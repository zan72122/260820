# 鉄瓶、うまれる。

岩手県の南部鉄瓶が、砂・火・鉄から生まれて暮らしの道具になるまでを体験する、タッチ操作主体の3Dモバイルゲームです。

このリリースでは、製造過程を **48工程** に分解し、工程順を保ったまま **4章・14の主操作** に束ねています。直接操作しない工程も省略せず、同じ工房内の短い自動工程として連続再生します。

## 完成版で実装しているもの

- タイトルから完成まで途切れず遊べる一本のゲーム進行
- 48工程の進捗保存と途中再開
- iPadの横画面・縦画面に応じたUIとカメラ
- 4章構成
  1. 土をつくる
  2. 火を流す
  3. 鉄をあらわす
  4. 黒を育てる
- 14の主操作
  - 型挽き
  - アラレ打ち
  - 焼型・油煙
  - 中子合わせ
  - 取鍋の持ち上げ
  - 湯口への運搬
  - 鋳込み
  - 湯返し
  - 型開け
  - 砂落とし
  - 鋳肌仕上げ
  - 釜焼き・黒仕上げ
  - 鉉の取付け
  - 最初の一杯
- 取鍋の傾き、重力、粘性、乱れ、流量から毎フレーム生成する湾曲した溶湯
- 厚み、側面、焼け、締め金具、注湯盆、湯口、ガス抜き、湯道、中子を持つ立体鋳型
- 二人の職人、長柄、取鍋の位置と姿勢の連動
- 砂塵、火花、蒸気、飛沫、炉火、冷たい窓光、空気遠近
- アラレ文様、粗い鋳肌、酸化皮膜、外面仕上げ、鉉、注湯まで変化する同一の鉄瓶
- 星・コイン・ゲームオーバーではなく、物質の反応と「隠れていた形が現れること」を報酬にする設計
- 手続き型Web Audioによる炉音、砂、鉄、溶湯、水、完成音
- 端末対応の触覚フィードバック
- PWA対応と、初回読込み後のアプリシェル／Three.jsキャッシュ
- 端末負荷に応じた描画品質の自動調整

## 写実性と4歳児向け補助

4歳児向けの補助は、工房内へ円、矢印、照準、成功範囲を浮かべる方法では実装していません。世界の見た目は保ったまま、次の値を別々に調整します。

- 入力の許容幅
- 動作速度
- 重量感
- 対象物の画面占有率
- カメラの高さと画角
- 砂塵量
- 溶湯の粘性、乱れ、太さ、発光
- 黒い艶
- UIと達成演出の存在感

設定には「写実優先」「4歳優先」「暗い工房」のプリセットがあり、各値をスライダーで微調整できます。設定は端末内へ保存されます。

## 起動方法

### 最も簡単な確認

このフォルダを静的Webサーバーで公開し、`index.html` を開きます。

```bash
cd nambu-ironware-foundry-3d
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

### GitHub Pagesなどへ配置

ビルド工程はありません。フォルダの内容をそのまま静的ホスティングへ配置できます。

Three.js 0.154.0は、起動時にjsDelivr、失敗時にUNPKGから読み込みます。Service Workerが利用できる環境では、読み込んだライブラリも次回用にキャッシュします。

## 操作

- タップ：アラレ打ち、楔打ち
- 円を描く：型挽き
- 上下ドラッグ：取鍋、鋳込み、湯返し、鉉、最初の一杯
- 左右ドラッグ：運搬、型開け
- なぞる：砂落とし、研磨、黒仕上げ
- タイトル／工房閲覧：ドラッグして視点をわずかに変える

失敗しても工程の最初へ戻されません。物質の反応を見ながら、その場で入力を直せます。

## 保存

次の内容をブラウザの `localStorage` に保存します。

- 完了した48工程
- 完了した主操作
- 現在の場面
- 各工程の最良精度
- 工房で遊んだ時間
- 全調整値

破損・旧形式・範囲外の保存値は起動時に正規化します。

## テスト

```bash
npm test
```

検証内容：

- 全JavaScriptとService Workerの構文
- 48工程の連番と重複のない割当て
- 4章の開始・終了工程
- 14主操作と対話工程の対応
- 必須UI、PWA manifest、アイコンの存在
- 未完了マーカーの混入
- 保存データの移行、重複排除、範囲制限、完成状態

この実行環境ではEGL／WebGLコンテキストを作れないため、自動検証は構文・構造・状態モデルまでです。最終的な光、影、タッチ、音、性能は、WebGLが有効なSafariまたはChromeで確認してください。
