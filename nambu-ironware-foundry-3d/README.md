# 南部鉄器 Foundry 3D Direction Lab

南部鉄器の製造工程を題材にした、iPad縦・横画面対応の3D方向性プロトタイプです。

## 起動

1. `index.html` をブラウザで開きます。
2. Three.jsをCDNから読み込むため、初回起動時はインターネット接続が必要です。
3. 右上の `▦` から13の重要シーン、`☰` から写実性・カメラ・重量感・操作補助・溶湯表現を調整できます。

## 実装済みの重要シーン

1. 鋳型をみる
2. 取鍋を支える
3. 湯口へ寄せる
4. 最初の一筋
5. 太さを保つ
6. 止め際を読む
7. 型へ楔を入れる
8. 型を開く
9. 砂を落とす
10. 鋳肌を整える
11. 黒い艶を育てる
12. 鉉を据える
13. 最初の一杯

## 方針

- 工程順序と物理的因果関係を守る
- 操作円や照準などを工房内へ浮かべない
- 溶湯は取鍋の傾きと重力から湾曲した流れとして描画する
- 鋳型に厚み、側面、砂の粗さ、締め金具、注湯盆、湯口、ガス抜きを持たせる
- 4歳児向け補助は世界を玩具化せず、入力許容幅や速度として実装する
- ゲームオーバーより、物質反応をもう一度起こしたくなる再操作を重視する

## 技術

- HTML / CSS / JavaScript
- Three.js 0.154.0（CDN）
- WebGL
- 外部3Dモデルや画像テクスチャは未使用

## 現段階の位置づけ

これは最終製品用アセットを用いた完成ゲームではなく、カメラ、空間構成、操作感、工程間の連続性を比較するための方向性プロトタイプです。人物、衣服、鋳型、取鍋、工具などはプロシージャルなプリミティブモデルで構成されています。

## 検証

- `node --check` により、分割したJavaScriptファイルの構文を確認済みです。
- この実行環境では管理ポリシーによりローカルURL／`file://` のChromium表示が遮断されたため、ブラウザでの最終スモークテストは未実施です。
- 実機ではSafariまたはChromeで `index.html` を開き、WebGL描画とタッチ操作を確認してください。
