# ゆうぐれのローラーすべりだい

夕暮れから夜へ移る公園。ローラー滑り台を滑ると、その回転が滑り台の下の
小さな発電機を回し、公園の照明が少しずつともります。

対象は 4 歳児、iPhone と iPad の Safari。文字による説明はなく、遊びの中で
「回転 → 発電 → 点灯」という因果を自分で見つけていく作りです。

## 遊びの流れ

1. 暗い三つの照明区画を、夕暮れの全景で見渡す
2. 上へスワイプして滑り台をのぼる
3. 頂上で指を離すと滑り出す
4. 身体の下でローラーが順に回り、通過したあとに path light が三灯だけ点く
5. カメラが滑り台の下側へ戻り、まだ回っているローラー・シャフト・発電機・
   蓄電インジケーターを一続きに見せる
6. ローラーを指で横になぞると、シャフトが回り、発電機の窓の機械式の針が上がり、
   近くの一灯がじわりと明るくなる。指を止めると針が下がり、灯りが弱くなる
7. 三つのセレクターレバー（道・屋根・木の立体の絵）から回路をひとつ選ぶ
8. 滑るたびに、選んだ区域だけが点灯する
9. 三区域がともったら、人の目線より少し高い位置から夜の公園を見る。
   区画をタップすれば再点灯の滑走へ、ローラーをタップすれば自由に手回しへ

得点、速度競争、障害物、転落、コイン、敵、アカウント、課金はありません。

## 操作

| 操作 | 動作 |
| --- | --- |
| 上へスワイプ | のぼる |
| 頂上で長押し | 待つ |
| 指を離す | 滑走開始 |
| ローラー上を横へなぞる | 手回し |
| レバーを大きく下へ倒す | 回路を選ぶ |
| 完成画面の区画をタップ | その区域を再点灯する滑走へ |

滑走中の指の動きは姿勢（腕を広げる／身体を小さくする）だけを変えます。
結果は決して失敗しません。

## 発電のモデル

- ローラーごとに角速度を持ち、身体の接地部が通ったところから順に回る
- 駆動帯のローラーの軸が梁を貫いて円板になり、ライン軸のゴム車を回す
- ライン軸の回転が発電機の出力になる。針はこの出力を遅れて追う
- 出力は選択中の回路だけに流れ、蓄電量は時間積分で貯まる
- 灯りの明るさ＝蓄電量＋瞬時出力の合成をフィラメントの遅れでなました値
- 回転を止めても蓄電のぶん短時間は灯りが残り、貯まった灯りは消えない
- 一回の滑走で貯まる量には上限があり、公園全体をいちどに照らすことはない

`dt` による時間積分と指数緩和のみを使っているため、フレームレートが変わっても
充電量と明るさは変わりません。

## 夜景の作り方

実光源は端末に応じて 2〜6 個までに制限し、明るいほうから順に器具へ割り当てます。
それ以外の光は次で表現しています。

- ディフューザー面だけを発光させる（器具の裏側は光らない）
- 地面へ落ちる光だまりを加算合成のデカールで描く（距離減衰と照射方向を持つ）
- 樹木のアップライトは幹に縦方向のウォッシュを一枚重ねる
- 接地影は焼き込んだ円盤インスタンスで、影マップは滑り台まわりだけ

色温度は path light と pavilion を暖色、機械インジケーターを淡い amber に寄せ、
虹色ネオン、青紫のリムライト、強い bloom は使っていません。

## 技術構成

- TypeScript + Three.js（WebGL 2 想定）+ Vite、静的配信のみ
- テクスチャ・ジオメトリはすべて手続き生成。外部アセットの読み込みはゼロ
- ローラー、樹木、光だまり、接地影はインスタンシング
- 静的な構造物はマテリアルごとにジオメトリを統合して描画コールを抑制
- 内部レンダー解像度は実測フレーム時間で動的に調整
- WebAudio のノードは使い回し、一発音のみ都度生成

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型検査
npm run build      # production build（dist/）
npm run preview    # build 済みの確認
```

### デバッグモード

`?debug=1` を付けて開くと、夕空の明るさ、lamp intensity、露出、bloom、
充電速度、ローラー速度、shadow quality、render scale、カメラプリセットを
その場で調整できます。production UI には出ません。最終値はすべて既定値として
コードに入っているので、デバッグモードなしで成立します。

### 自動確認

`tools/play.mjs` は実際のジェスチャーだけで三回の滑走と三区域の点灯までを
通します。`tools/shoot.mjs` はカメラチェーンの各ショットを端末サイズ別に
撮影します。どちらも Playwright + Chromium で動きます。

```bash
node tools/play.mjs                          # 通し確認（要 npm run dev）
URL='http://localhost:4173/?e2e=1' \
  node tools/play.mjs                        # production build に対して通す
DEVICE=ipadL node tools/shoot.mjs            # 画面サイズ別のショット確認
node tools/orient.mjs                        # 途中で画面を回して再構図を確認
```

いずれも `?e2e=1` を付けたときだけ有効になる自動化用のフックを使います。
通常のプレイでは何も公開しません。
