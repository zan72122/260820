# Mirror Glaze Atelier / ミラーグレーズ アトリエ

4歳の女の子が iPhone / iPad の Safari で遊べる、写実的な 3D ミラーグレーズ
ゲームです。凍ったアントルメをシリコーン型から外し、ステンレスのラックへ
運び、粘度のあるグレーズを指で流して、鏡のようなケーキに仕上げます。

- 実際の透視投影カメラ・深度テスト・3D 照明を持つ WebGL2 空間（CSS 疑似 3D ではありません）
- グレーズの被覆はケーキ表面の UV 空間で解く薄膜シミュレーション。指の動きが
  そのまま模様になります
- 操作は一本指のみ。タップとドラッグ、押している間だけ注ぐ、それだけです

## 起動

```bash
npm install
npm run dev      # http://localhost:5173/
npm run build    # 型チェック + 本番ビルド (dist/)
npm run preview  # ビルド結果の確認
```

## 遊びかた

1. **型を外す** — 画面を上へ引っぱるとシリコーン型が撓んで外れます
2. **ラックへ運ぶ** — ケーキを指でラックまでドラッグ（近づくと吸い付きます）
3. **色を選ぶ** — 作業台の 3 つのピッチャーをタップ
4. **注ぐ** — 押している間だけ注がれ、指を動かすと落下点が動きます
5. **仕上げ** — 側面の滴が落ち着き、カメラが低い位置へ回り込みます
6. **もう一度** — 同じ色 / 別の配色を大きなボタンで選べます

## 設計メモ

- **グレーズ被覆**: ケーキ表面を `(u, v)` の 2D グリッドとして扱い、
  `ポテンシャル = 地形高さ + 膜厚` の差で流量を解きます。重力方向（v 増加）は
  降伏応力を超えないと動かず、横方向はより軽い閾値で均されるため、
  「筋を残しながら最後は鏡面に均る」挙動になります。色は質量と一緒に運ばれるので、
  後から重ねた色が前の色を押して縞や渦を作ります。
- **指で隠れない**: 注ぎ位置は指のスクリーン座標より上へオフセットし、
  ピッチャーはさらにその上に置かれます。
- **失敗しない**: 落下点は `tanh` でケーキ内へ軟らかく収束し、外し続けても
  美しい結果になります。各フェーズには待ちすぎたときの自動進行があります。
- **性能**: devicePixelRatio は上限付きで自動調整。影は主照明のみ。
  シミュレーションは端末解像度より低い専用レンダーターゲットで実行します。
