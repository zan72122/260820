# もちつき ぺったん

4歳から遊べる、日本の冬の「餅つき」をテーマにしたモバイル Web ゲームです。
古民家の土間で、蒸籠から湯気の立つもち米を臼に入れ、杵でつき、
白くつやの出た餅を **びよーん** と伸ばし、ちぎって丸め、鏡餅に仕上げます。

- **WebGL 3D**（three.js / 透視投影・実ジオメトリ・影・接地・材質反応）
- CSS の擬似3Dは不使用
- 文字を読まなくても遊べる（絵と動きだけで操作を伝える）
- 音はすべて WebAudio で合成（外部音源ファイルなし）
- テクスチャもすべて Canvas2D で手続き的に生成（外部画像ファイルなし）

## 遊びかた（文字なしで伝わるようにしてあります）

| 場面 | 操作 | 画面の合図 |
|---|---|---|
| はじめ | まんなかのボタンを押す | 杵と臼の絵が息づく |
| もち米を入れる | 見ているだけ | 蒸籠が運ばれて湯気が立つ |
| つく | 画面を **下** になぞる（タップでも可） | 下向きの矢印と手 |
| のばす | 画面を **上** になぞって、そのまま持ち上げる | 上向きの矢印と手 |
| ちぎる | 画面を **横** になぞる | 横向きの矢印と手 |
| まるめる | 画面を **ぐるぐる** なぞる | 円を描く矢印と手 |

上の粒（●）が進み具合です。タイミングを外しても失敗はありません。
杵は必ず気持ちよく落ち、餅は必ず伸びます。

## 動かしかた

ES モジュールを使うため、**ローカルの Web サーバー経由**で開いてください
（`file://` では読み込めません）。

```bash
cd <このリポジトリ>
python3 -m http.server 8000
# → http://localhost:8000/ を iPhone / iPad の Safari で開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。

### 開発用の URL パラメータ

| パラメータ | 意味 |
|---|---|
| `?speed=4` | ゲーム内時間を 4 倍速で進める（0.1〜12） |
| `?fast=1` | 影と高DPRを切って軽くする（動作確認用） |

## 構成

```
index.html          画面の枠と CSS（操作ヒントのアニメーションもここ）
vendor/             three.js（MIT）
src/
  main.js           進行（場面遷移）・入力・演出のまとめ役
  env.js            古民家の土間、冬の庭、照明、環境マップ
  tools.js          臼・杵・手・橙
  mochi.js          餅の変形メッシュ（粒 → まとまり → 伸び）
  fx.js             湯気・手粉・米粒・雪・きらめき
  audio.js          ペッタン / 湯気 / 米 / 伸び / 丸めの合成音
  camera.js         場面ごとの構図と、画面比に応じた寄り引き
  ui.js             文字を使わない操作ヒントと進み具合
  textures.js       木・土・漆喰・雪・米粒などの手続き的テクスチャ
```

## 実装メモ

### 餅
`src/mochi.js` の `MochiMass` は球状トポロジのメッシュを毎フレーム作り直します。
半径は **絶対高さ** の関数として決めており、

- 臼の中の塊（下）
- 細くくびれた首（中）
- 杵にくっついた頭（上）

の3つを高さ方向のガウス関数で混ぜています。伸ばすほど首が細くなり、
下の塊は体積保存的に痩せます。`cohesion`（0→1）が粒感（法線の強さ・
凹凸の振幅・色・つや）を一括で動かし、蒸し米から白い餅へ連続的に変わります。

引き上げるたびに角度方向の倍音（2・3・5次）を振り直すので、
**同じ形には二度とならず、伸ばし方によって餅の形が変わります。**

### 手返し
実際の危険な工程は演出しません。奥から手がひと返しするだけの短い補助
アニメーションで、杵は手が入っている間は絶対に落ちません（入力は queue されます）。

### カメラ
自由操作はありません。場面ごとに構図を決め、画面比に応じて
距離を解き直すので、iPhone の縦・横、iPad の縦・横のいずれでも
杵と臼が切れません（`src/camera.js`）。
