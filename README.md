# ゆきの したの かわ — 流雪溝あそび

雪国の細い道の下に隠れている「流雪溝」を、4歳ぐらいの子どもが一本指で遊べる
モバイル Web ゲームにしたものです。iPhone / iPad の Safari を想定しています。

**核になる驚きは二つだけです。**

1. 金属の蓋を持ち上げると、道の下に水が流れているのが見える。
2. 雪を入れると、その水が雪を運んでいってしまう。

失敗も、制限時間も、数字の UI も、長い説明もありません。

## あそびかた

1. 「あそぶ」を押す（この一回のタップで音が鳴るようになります）。
2. 光っている金属の蓋をタップする → 蓋が持ち上がり、カメラが地面の下へ潜って、
   道路の断面と水路が同時に見える構図に切り替わります。
3. 道に積もった雪の山を指でつまんで、穴の近くまでドラッグして放す。
   雪の山をポンと叩くだけでも、スコップが雪をすくって穴へ運びます。
4. 落ちた雪塊が水に飲まれ、くるくる回りながら崩れ、暗がりへ流れて消えていきます。
5. その投雪口のまわりの雪がなくなると蓋が閉まり、次の投雪口へ。三つ終わると
   最初から遊べます。

右上のボタンは、音の入切と、はじめからやり直しです。

## うごかしかた

ビルド不要・依存パッケージのインストール不要です。静的ファイルを配信するだけ。

```sh
python3 -m http.server 8000
# → http://<PCのIPアドレス>:8000/ を iPhone / iPad の Safari で開く
```

ES modules を使うため `file://` では動きません。必ず HTTP で開いてください。

## 中身

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面の枠、タイトル、ヒント、セーフエリア対応 |
| `src/main.js` | 起動、リサイズ、入力、描画ループ、画質の自動調整 |
| `src/world.js` | 道・家・塀・地下水路・蓋などの 3D シーン構築 |
| `src/game.js` | カメラ演出、指の操作、雪塊の物理と水流での搬送 |
| `src/textures.js` | 雪 / アスファルト / 縞鋼板 / コンクリート / 水 の手続き的テクスチャ |
| `src/noise.js` | 値ノイズ、fBm、ハイトマップ→法線マップ変換 |
| `src/audio.js` | WebAudio による効果音の合成（音声ファイルなし） |
| `vendor/three/` | three.js r169（同梱、CDN 非依存） |

画像・音声のバイナリ素材は一つもありません。地面の凹凸はテクスチャと同じ高さ場から
生成しているので、見えている轍と実際のジオメトリの凹凸が一致します。

## 地上と地下をどうつないでいるか

シーンは実寸のジオメトリで組んだ「道の輪切り」です。地上の街並みの表示中は
クリッピング平面を遠くに置いて何も切らず、蓋を開けた瞬間にその平面を手前から
道路の側溝の位置まで動かします。手前側の地面・塀・家が切り取られ、コンクリートの
断面（雪 / アスファルト / スラブ / 砂利）が現れて、道路面と水路が一画面に並びます。
そのため「投げた雪」と「流れる雪」が一度も画面から切れません。

## 対応と性能

- 一本指のみ。ピンチ・回転・二本指操作は使いません。
- 縦横どちらでも遊べます。回転すると構図（カメラの寄りと角度）が組み直されます。
- `env(safe-area-inset-*)` でノッチとホームインジケータを避けています。
- 画素密度は最大 2 倍まで。フレームが落ちるときは自動で 1.5 → 1.15 倍に下げ、
  影の解像度も落とします。
