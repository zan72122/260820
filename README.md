# 光のトンネル工房 (Light Tunnel Workshop)

4歳児が iPhone / iPad のブラウザで遊ぶ、写実寄りのモバイル Web ゲームです。

半透明 FRP の試験パネル・太陽光・滑走面を流れる薄い水膜・筒の角度、
この四つが噛み合ったときにだけ、暗いウォータースライダーの内部に
動く光模様が生まれます。子どもはそれを**自分で発見**します。

色を選んで筒を塗るゲームではありません。

---

## 起動方法

必要なもの: Node.js 18 以上。

```bash
npm install
npm run dev          # http://localhost:5173/ を開く
```

本番ビルドと確認:

```bash
npm run build        # 型検査 (tsc --noEmit) + vite build
npm run preview      # http://localhost:4173/ でビルド結果を確認
```

`dist/` はそのまま静的ファイルとして配信できます。
ログイン・広告・課金・バックエンドは一切ありません。

実機で試すときは同じ LAN から `http://<PCのIP>:5173/` を開いてください
（`vite.config.ts` で `server.host = true` にしてあります）。

## 遊び方（子どもには一切説明しません）

1. **暗い筒**。床にぼんやりした一筋の光があるだけ。棚の試験パネルが風で少し揺れ、
   縁を太陽光が透過する。
2. **パネルを運ぶ**。棚の一枚を筒の試験ポートへ大きくドラッグする。
   位置合わせは不要 — 近づけば重さを感じる動きでガイドレールへ入り「コトン」と座る。
   ハッチが開き、まず**素の日光の四角**が筒内に落ち、パネルが座った瞬間に
   それが**静止した光模様**へ変わる。
3. **クランプを倒す**。ポートのどこを触ってもよい。四つのカムが順に噛む。
4. **リングを回す**。指で円を描くとパネルが面内で回り、筒内の模様も同じだけ回る。
   外のパネルと中の模様は、分割画面ではなく**カットアウェイの一続きのカメラ**で同時に見える。
5. **水弁を引く**。薄い水膜が滑走面を覆い、静止していた模様が揺れ、伸び、
   筒の奥へ走り出す。ここが最大の「謎から理解へ立ち上がる瞬間」。
6. **工房遊び**。一回に一つだけ変数が変わる構成：
   パネルを変える → 角度を変える → 水量を変える → テストラフトを流す。
   カメラは常に「いま生きている操作」と「筒内の結果」を同じ画面に収める。
7. **ラフト**。前へスワイプすると空のテストラフトが発車し、
   外観 → 筒内の固定レールカメラ → 後方からの穏やかな追従、の三視点が
   カットなしでつながる。光の輪を通るとゴム面・水膜・白い試験体へ色光が乗る。

必須操作は**一指のみ**。矢印・文章・手のアイコンは常時表示しません。
迷ったときの誘導は物理現象だけ（パネルの揺れ、リングの微回転、弁の震え、筒内の淡い明滅）。

## 実装の要点

| 課題 | 実装 |
| --- | --- |
| 光模様 | 受光面の各画素から**太陽方向へ逆にレイを飛ばし**、パネル平面との交点をパネル座標に落として模様関数を評価する。つまり筒内の模様は文字どおりパネルの影。リングを回すとパネル基底が回り、模様も回る（`src/render/optics.ts`） |
| 水の影響 | full fluid simulation は不使用。パネル座標を water film の進行波でずらし（ripple）、流量に比例して下流へ送り（advection）、フットプリント自体も引き伸ばす |
| caustics | 手続き生成の tileable Voronoi テクスチャ 2 層をスクロールし、光模様に乗算 |
| 筒内の暗さ | 環境マップは「筒の中」を知らないので、開口方向と法線の内積＋開口端からの距離で遮蔽項を作り、間接光を落とし、直射をほぼ殺す |
| 水膜 | flow map 相当の進行波でノーマルを曲げ、泡筋テクスチャをスクロール。透明面は水膜と試験パネルだけ |
| 半透明 FRP | transmission パスは使わず、透過率つき transparent + clearcoat + 前方散乱項。厚みは断面の実形状（18 mm、面取り、クランプ穴）で見せる |
| ラフト | spline follower（`placeRaft`）。物理シミュレーションではなく決められた床の上を走る |
| カメラ | 決められたショット間のブレンドのみ。自由カメラなし、roll ゼロ |
| 縦画面 | 横 FOV を保ったままカメラを後退させ（`CameraRig.dolly`）、余った高さを筒とポートに配る |
| 遅延ロード | 試験筒・ポート・棚を先に描画してから、工場遠景を dynamic import |
| 品質設定 | 右上の歯車から 低 / 中 / 高。水滴数・caustics 解像度・影解像度・反射強度・pixel ratio が変わる。フレーム落ちが続くと自動的に一段下げる |

### 状態

パネル種別・角度・水量・太陽角・雲量は `OpticsState` 一つに集約され、
毎フレーム同じ uniform ブロックへ流し込まれます（`src/render/optics.ts`）。
「外を回すと中が回る」が壊れないのは、経路がここ一本しかないからです。

### 素材

テクスチャ・ジオメトリ・音は**すべて実行時に手続き生成**しています。
外部アセットのダウンロードはありません。詳細は `ATTRIBUTIONS.md`。

## 動作確認済みの環境

- Chromium (WebGL 2 / SwiftShader) でのプレイスルー自動テスト
  `tools/play.mjs` … パネル装着 → クランプ → 回転 → 注水 → パネル交換 →
  ラフト発車 → ライド三視点 → ランアウト → 工房へ復帰、までを実際の
  pointer イベントで通し、コンソールエラーが出ないことを確認しています。
- 縦 414×760 / 横 900×600 の両方でレイアウトを確認。

GPU の無い環境（SwiftShader）ではフレームレートは実機と比較になりません。
FPS・アニメーションの滑らかさ・最終的な見た目の評価はハードウェア
アクセラレーションのある実機で行ってください。
