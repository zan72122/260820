# はねかえり素材研究所

屋外の小さな材料試験パビリオンで、球を落として「床によって跳ね方が変わる」ことを
自分の一回の操作から発見し、そのまま素材の組み合わせを試して遊ぶ 3D Web ゲームです。

対象は 3〜6 歳（中心は 4 歳）。文章・数値・反発係数・採点表は一切表示しません。
iPhone / iPad の Safari で、縦画面・横画面の双方に対応します。

---

## 起動手順

```bash
npm install
npm run dev        # 開発サーバ（http://localhost:5173、LAN からも到達可）
```

実機確認は、同じ Wi-Fi 上の iPhone / iPad から `http://<PC の IP>:5173/` を開きます。

```bash
npm run build      # 型チェック＋本番ビルド → dist/
npm run preview    # dist/ を配信して確認
```

`dist/` は完全な静的サイトです。特別なサーバ設定は不要で、
任意の静的ホスティングにそのまま置けます（相対パス `base: './'` でビルド）。

外部通信は一切ありません。広告・ログイン・オンラインランキング・
外部分析 SDK は含まれず、画像や音声のダウンロードも発生しません
（後述のとおり、素材テクスチャも効果音もすべて実行時に生成します）。

### 計測モード

`?debug=1` を付けて開くと、端末内だけの計測パネルが表示されます。
通常のプレイヤーには一切表示されず、ネットワークへも送信しません。

## 遊びの流れ

| 段階 | 内容 | 開放条件 |
| --- | --- | --- |
| 試行 1 | 厚いゴム床。球・高さは機械側が固定。子どもが触れるのは解除リングだけ | 最初から |
| 試行 2 | トレイが自動で回り、砂の面が出る。同じ球・同じ高さ | 試行 1 の直後 |
| 段階 A | 床を選ぶ（トレイを左右にスワイプ／7 種類） | 試行 2 の直後 |
| 段階 B | 球を選ぶ（前面レールの防塵カバーが開く／6 種類） | 自分で床を変えて試したあと |
| 段階 C | 高さを変える（クランプの取っ手を上下へ／3 段） | 自分で球を変えたあと |
| 段階 D | 三枚の床パネルを地面の台へ置いて連鎖を作る | さらに試行を重ねたあと |

各段階には時間による保険もあり、同じ試験を繰り返しているだけの子どもにも
いずれ次の自由度が開きます。逆に、開いていない操作対象は画面上に
「押しても何も起きないもの」として現れません（球のレールは物理的な蓋で閉じています）。

### 操作

- **解除**：大きなリングを下へドラッグ
- **床変更**：トレイ（または画面下側）を左右へスワイプ
- **球選択**：前面レールの球をクランプへドラッグ（タップでも可）
- **高さ**：クランプの取っ手を上下へドラッグ（3 つの広い領域へ吸着）
- **自由配置**：ラックの見本タイルを地面の台へドラッグ
- **痕跡消去**：ブラシをつかんで面の上を動かす

砂のくぼみ、粘土の跡、水滴は自動では消えません。
掃除したくなったときにブラシで消します。

## 設計上の約束

### 教えすぎない

- 「ゴムはよく跳ねます」といった説明音声・字幕は出しません。
- 最初から全素材の答えを実演しません。
- 赤・黄・青などの色で性能を符号化しません。素材は**光への応答**で見分けます。
- ヒントは操作方法だけを示し、結果は示しません。段階は
  ①球がクランプ内で小さく揺れる → ②解除リングがわずかに下がる →
  ③「ぽとん」という短い音 → ④リングが一度だけ引かれて戻るゴースト動作、の順。
  **跳ね返りの高さは決して予告しません。**

### カメラ

主カメラは 1 台だけで、解除から最初の跳ね返り頂点まで切り替えません。

フレーミングは「解除位置」と「衝突点」を含む世界空間の箱を計算して合わせます。
どんな素材でも受け取ったエネルギー以上は返せないので、落下全体が入る画角には
最初の頂点が必ず含まれます。つまり**跳ね返りの途中で引く必要がなく**、
カメラ操作で答えを先に見せてしまうことがありません。

- 落下中：球を追って急降下しません（画角は固定）。
- 衝突時：別カメラへ切り替えず、主カメラがごくわずかに寄ります。
- 衝突後：最初の頂点を過ぎてから、痕跡へ寄ります。
- 二試行：同じ画角・同じ高さ・同じ速度感を使います。
- 縦画面は落下の垂直距離を最大限に使い、横画面は連鎖の水平方向を広く見せます。
- 解除リングは落下線から離れた位置に吊られ、腕はクランプと一緒に前後へ動きます。
  **入力中の指が衝突点を隠しません。**

## 技術構成

TypeScript + Three.js + Vite。ランタイム依存は `three` のみです。

```
src/
  core/      app.ts        全体の組み立て・ループ・段階遷移
             quality.ts    品質段階の自動判定と実行時の下げ判断
  physics/   params.ts     床 7 種・球 6 種の内部パラメータ表
             engine.ts     固定タイムステップの落下シミュレーション
  materials/ texgen.ts     手続き的 PBR テクスチャの生成器
             recipes.ts    素材ごとのレシピ（色・粗さ・法線・AO）
             library.ts    遅延ベイクとキャッシュ
             envmap.ts     手続き的な環境マップと空
  world/     pavilion.ts   建屋・地面・照明
             rig.ts        門型フレーム・クランプ・解除リング
             turntable.ts  7 枚の試料を載せる回転トレイ
             panel.ts      変形する試験面（高さ場＋痕跡キャンバス）
             water.ts      浅い水トレイ（波紋シェーダ）
             ball.ts       球の圧縮・回転・接地影
             particles.ts  プール済みの粒子
             shelf.ts / chain.ts / tools.ts
  camera/    director.ts   単一カメラのフレーミング
  audio/     engine.ts     WebAudio による衝突音の合成
  ui/        interaction.ts 全ジェスチャ
             hints.ts      段階的ヒント
             debug.ts      ?debug=1 の計測パネル
  state/     game.ts       段階・開放条件・計測
```

### 素材の見分けを色に頼らない

画像アセットは 1 枚も同梱していません。各素材は「レシピ関数」として書かれていて、
起動時に base color / roughness / metalness / AO / 法線 を 1 テクセルずつ計算し、
3 枚のタイル可能なテクスチャ（albedo、ORM パック、法線）へ焼き込みます。

そのため粗さを面全体で均一にせず、手垢・擦れ・濡れ・粉塵で局所的に変化させられます。

- ゴム：柔らかく広いハイライト、細かな粒状 normal、中央だけ打痕で磨かれて滑らか
- 砂：最大の roughness、cellular な粒、粒間に落ちる強い AO
- 濡れ粘土：低い所に水膜が溜まり、そこだけ roughness が落ちる
- 木：年輪・木口・乾湿差、局所的な擦れ
- 金属：正しい metalness と環境反射、方向性のある微細な傷、縁の磨耗
- フェルト：交差する繊維 normal、強い拡散反射と sheen
- 浅い水：青い床にせず、反射・透過・底面・さざ波で示す

球も同様に、金属の鋭い反射／木の木目／ゴムの広いハイライト／フォームの細孔／
濡れた球の水膜で見分けます。

環境マップは、空・屋根・実用照明・地面の照り返しを記述した小さなシーンを
PMREM で 1 度だけ前処理したものです（HDR のダウンロードなし）。

### 衝突の作り方

汎用物理エンジンは使わず、固定タイムステップ（1/180 秒）の薄いゲーム層を持ちます。
接触は「演出された接触」で、接地した瞬間に

- 接触時間（床の柔らかさ × 球の柔らかさ）
- 床が沈む量と球が潰れる量（柔らかい方が多く受け持つ）
- 離れるときの法線速度（`床の反発 × 球の反発`）

を確定し、その区間を 1 本の滑らかなストロークで動かします。
結果として接触が数フレーム続くので、**潰れと押し返しが実際に見えます**。
また同じ組み合わせなら必ず同じ結果になるため、
一回目と二回目の差が「床を変えたからだ」と読めます。

表現は手法を分けて負荷を抑えています。

| 現象 | 実装 |
| --- | --- |
| ゴムの圧縮 | 接触中だけの一時的な窪み（高さ場に加算） |
| 砂のクレーター | 高さ場を掘り、縁を盛り上げ、粒子を少量飛ばす |
| 粘土の跡 | 高さ場＋濡れた暗い痕跡をキャンバスへ描画 |
| フェルトの沈み | ゆっくり戻る成分として高さ場に保持 |
| 水 | 波紋シェーダ＋しぶき粒子＋球を濡らす |
| 球の軌道 | 決定論的な剛体 |

痕跡は自動で消えません。掃いた分だけ、掃いた場所が戻ります。

### 音

すべて WebAudio で合成しています（音声ファイルなし）。

床ごとに発音方式そのものを変えます — ゴムは低い三角波の急降下、砂は純粋な帯域雑音、
粘土は湿った低い打撃、木は少数の減衰モード、金属は非調和な倍音列と長い余韻、
フェルトはほとんど無音、水は上昇する泡＋しぶき。
その上に球側の共鳴が重なるので、同じ床でも中空金属球と発泡球では倍音と余韻が変わります。
質量は音量とピッチに、衝突速度は明るさに効きます。

転がり音は面と速度で連続的に変化します。落下中に風切り音は付けません。

### 性能

WebGL 2 を前提とし、起動時に端末から品質段階を推定して、
実行中もフレーム時間の 80 パーセンタイルを見て必要なら段階を下げます。

- devicePixelRatio に上限（2 / 1.7 / 1.35）
- 動的な影は 1 灯のみ
- **球直下の接地影は品質を下げても必ず残します**（球が浮いて見えることを避けるため）
- 粒子・痕跡・音声ノードはプール、実行中に確保しません
- 環境反射は前処理済み、金物はインスタンス描画
- 素材テクスチャは遅延ベイク。起動時は最初の 2 面だけ焼き、
  残りは 1 フレーム 1 枚ずつ埋めるので、**読み込み後すぐ第一試行に入れます**
- 非表示になったら描画と音を止めます
- 画面回転では球・床・痕跡・試行段階を保持します
  （セッション記憶があるので、Safari がページを破棄しても続きから戻れます）

### 計測（`?debug=1` のときだけ）

解除リングへ触るまでの時間／二つ目の床を自力で試したか／同じ球で床だけ変えたか／
理解後に球または高さを自発的に変えたか／三素材連鎖を作ったか／同じ試験の反復回数／
現在の球・床パラメータ／FPS・draw call・テクスチャ推定メモリ・pixel ratio。

いずれも端末内に留まり、ネットワークへは送りません。

## 開発時の確認

```bash
npm run typecheck
npm run build
node tools/smoke.mjs iphone-portrait      # 一連の流れを自動操作して検証
node tools/shots.mjs iphone-landscape     # 各段階の画面写真を撮る
node tools/tour.mjs water,clay,felt       # 指定した床材へ順に落として撮る
node tools/probe.mjs yard                 # 各操作対象の画面位置と当たり判定を出す
```

視点は `iphone-portrait` / `iphone-landscape` / `ipad-portrait` / `ipad-landscape`。

`tools/` の各スクリプトは Chromium（Playwright）で実際に解除リングを引き、
床を替え、球を替え、連鎖を組むところまでを操作して状態を検証します。
ヘッドレスの SwiftShader 上で動くため、**フレームレートと絵の品質の判断には使えません**。
それらは GPU が有効な実機で確認してください。
