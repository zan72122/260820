# たけのこ ほり

春先の竹林に入り込んで、**土の中にかくれたたけのこを探して掘りだす** モバイル向け
Web ゲームです。iPhone / iPad の Safari で、指 1 本だけで遊べます。

WebGL の透視投影と実ジオメトリで作った 3D 空間です（CSS 疑似 3D は使っていません）。
外部のモデルや画像は 1 枚も使わず、地面・落ち葉・苔・竹の節・たけのこの皮まで、
すべてその場で手続き的に生成しています。

---

## あそびかた

1. **さがす** — 竹林の地面を見て、土が盛りあがっている / 割れている /
   先っぽがのぞいている場所をタップする
2. **はっぱを はらう** — 指でこするように動かして落ち葉をどける
3. **まわりを ほる** — 指でまるくなぞって、たけのこのまわりを掘る
   （途中で地面が断面になり、土の中のたけのこの長さと向きが見える）
4. **したを きる** — 断面の接写で、刃を横にスッと動かして根元を切る
5. **ひっぱる** — 指を上に動かすと、土が崩れてたけのこがスポンと抜ける
6. かごに入れて、つぎの場所へ

操作はこの 4 つだけです。小さなボタン、細かい照準、時間制限、失敗はありません。
たけのこが無い場所を触っても、落ち葉がふわっと舞ったり石が顔を出したりするだけで、
少し待つか 2 回外すと、正解の場所にやさしく光の輪が出ます。

掘る位置が多少ずれても大丈夫です。指の **角度だけ** を見ているので、
正しい円周に自動で吸着します。

## うごかしかた

```bash
npm install
npm run dev      # 開発サーバ (http://localhost:5173)
npm run build    # 本番ビルド -> dist/
npm run preview  # ビルド結果を確認 (http://localhost:4173)
```

### iPhone / iPad で遊ぶ

`npm run dev` は `--host` つきで起動するので、同じ Wi‑Fi にいる実機から
ターミナルに表示される `http://<PCのIP>:5173/` を Safari で開けばそのまま遊べます。
`dist/` は静的ファイルだけなので、任意のホスティングに置いても動きます。

ホーム画面に追加するとフルスクリーンになります（`apple-mobile-web-app-capable` 対応）。

### URL パラメータ

| パラメータ | 意味 |
| --- | --- |
| `?fast=1` | 軽量・決定論モード。影と粒子を切り、画素比 1、演出を短縮する（E2E 用） |
| `?seed=<数値>` | 竹林とたけのこの配置を決めるシード |

## 画づくり

カメラはすべてゲーム側が決めます（自由カメラはありません）。

| 場面 | 画 |
| --- | --- |
| 導入 | 竹林の奥へ向かってゆっくり下りるショット。空間の深さを見せる |
| さがす | 子どもの目の高さ（約 1.35m）から地面を見わたす |
| 寄る | 地面近くまで下りて、候補地点を正面に置く |
| 掘る | 斜め上から。掘った穴の深さが読める角度 |
| 断面 | 手前の土を切り取り、地層のかべの中にたけのこの全長が見える |
| 切る | 同じ断面のまま根元へ接写。刃先と根元の関係がはっきり分かる |
| 抜く | 引いて、土が崩れる瞬間とたけのこ全体を見せる |
| かご | 竹かごに入るところ |

縦画面と横画面で必要な寄りが変わるため、**注視点からのオフセットごと**画面比で
スケールしています。方向を保ったまま距離だけ変えるので、縦画面で引いても
カメラが土にめり込みません。接写だけは穴の中に構える都合上、距離ではなく
画角で画面比を吸収します。遊んでいる途中で端末を回しても、その場で構図を取り直します。

## 技術メモ

### 掘る仕組み

本格的な破壊シミュレーションは使っていません。掘り場は
**極座標の高さ場**（48 セクタ × 11 リング）で、指が進んだ角度ぶんだけ
まわりのセクタをなだらかに深くします。

- 指の角度だけを見るので、半径がずれても正しい円周に吸着する
- 掘った深さで頂点カラーを「乾いた明るい土 → 冷たく濡れた黒土」に変える
- 掘るほど、ふちに掘り出した土の塊が黄金角の順で積もっていく
- 2 周ほどで掘りきれる速さに調整（4 歳児が飽きない長さ）

### 断面表示

`renderer.localClippingEnabled` によるローカルクリップ面を、地面・掘り場の土・
落ち葉のマテリアルにだけ適用します。たけのこと道具はクリップしないので、
土だけが切り取られて中身が見えます。切り口が空洞にならないよう、
いま掘れている形にあわせて地層のかべ（5.2m 幅）を毎回作りなおしています。

### テクスチャ

すべて canvas で生成しています。タイル境界が見えないよう、
**周期つき Perlin ノイズ**（`noise2p` / `fbmTile`）を使い、
タイル座標が 1 周したところで必ず値が一致するようにしています。
法線マップは高さマップから Sobel で作っています。

### モバイル Safari 向けの配慮

- 画素比の上限 2、`touch-action: none` と `preventDefault` でスクロール／ズームを封じる
- ポインタは 1 本目だけを追跡（多指でも壊れない）
- インスタンス描画と 3 段 LOD、たけのこの皮・葉先・根はジオメトリをまとめて
  1 メッシュに（描画コール 250 → 98）
- fps が落ちたら自動で画素比を下げ、さらに落ちたら影を切る
- WebGL コンテキスト消失をハンドリング
- 効果音は WebAudio で合成（外部ファイルなし）。iOS の制約に合わせて初回タップで解錠

## テスト

```bash
npm run lint      # ESLint
npm run test:e2e  # Playwright (Chromium / SwiftShader)
```

E2E は実際のポインタイベントで指の動きを再現し、次を確認しています。

- 起動して WebGL の竹林が実ジオメトリで立ち上がる（コンソールエラー無し）
- 導入ショットから探索へ進む
- はずれの場所を触っても止まらず、ヒントが出る
- **たけのこを 1 本掘ってかごに入れられる（縦画面）** — 落ち葉を払い、掘り、
  断面が出て、根元を切り、引き抜くまで
- あそんでいる途中で画面を回しても続けられる
- 横画面でも一周できる

> GPU の無い環境（SwiftShader）で走らせているため、E2E では fps や
> 見た目の最終品質は判定していません。そこは実機で確認する前提です。

`scripts/shots.mjs` は各場面のスクリーンショットを撮る開発用の道具です。

```bash
npm run preview &
node scripts/shots.mjs portrait    # shots/portrait/*.png
node scripts/shots.mjs landscape   # shots/landscape/*.png
```
