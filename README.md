# どろんこ治水工事

雨上がりの砂場で、水門をあけて、指で溝をほって、水の道をつくる
3D ウェブゲームです。iPhone / iPad の Safari で、そのまま遊べます。

文字は読めなくても遊べます。説明も、点数も、制限時間も、ゲームオーバーも
ありません。

## 遊びかた

1. 大きな丸いボタンを一度おす（音が使えるようになります）
2. 木の水門の取っ手を、指で上へ引く（引いた分だけ水が出ます）
3. 砂を指でなぞると、太い溝ができます
4. 水は、その溝をたどります
5. 堤防が切れたら、泥を押しつけてふさぐか、別の道をほります
6. 下の池に水がとどくと、葉の舟が浮かびます
7. あとは、絵で「おなじ砂場 / ちがう砂場 / 水だけ」を選べます

## 動かしかた

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 本番ビルド (tsc --noEmit + vite build)
npm run preview    # ビルド結果の確認
```

`dist/` は静的ファイルのみです。任意の静的ホスティングに置けます。

## 技術構成

| 領域 | 方式 |
| --- | --- |
| 基盤 | Vite + TypeScript + three.js (WebGL 2) |
| 地形 | 72 × 153 の height field。指の軌跡で局所的に減算し、掘った砂は縁へ積む |
| 水 | virtual pipes 法の浅水シミュレーション。固定タイムステップ 1/60 秒、内部 2 サブステップ |
| 水門 | オリフィス流量式で開度に比例した流量。壁面はフラックスを遮断 |
| 濡れ | セルごとの含水率を DataTexture 化し、砂マテリアルの色・粗さ・法線を変える |
| 決壊 | 流速と河岸の高低差から侵食。乾いた側へ切れたときだけ「決壊」として扱う |
| 影・遮蔽 | 一灯の動的影 + height field からの水平線遮蔽 (horizon AO) |
| テクスチャ | すべて手続き生成（起動時に生成、外部画像の読み込みなし） |
| 音 | すべて Web Audio で合成。日本語オノマトペのみ SpeechSynthesis |
| カメラ | 手動操作なし。画面ごとに必要な地面の範囲から距離を解く演出専用リグ |

外部通信、ログイン、広告、解析 SDK、個人情報の送信はありません。
観察用データも端末内のみに保存します。

## 画面

- iPhone 縦 / 横、iPad 縦 / 横に対応
- 縦画面は上流から下流を縦に、横画面は上流側から見て流路を左右に組み替え
- 回転しても地形・水量・濡れ・泥の補修は保持されます
- 内部解像度は上限つきで、フレーム時間に応じて自動的に上下します

## 開発者向け観察モード

URL に `?debug=1` を付けたときだけ、次を表示します。

- 最初の接触までの秒数 / 最初に水を流すまでのヒント数 / 池に届くまでの時間
- 二回目に異なる水路を掘ったか / 水門操作の回数
- FPS、draw call、三角形数、内部解像度
- 水セルの簡易可視化

データは `localStorage` のみに保持し、外部へは送りません。
通常のプレイでは完全に非表示です。

## 検証用ツール

`tools/` に Playwright (Chromium) のスモークスクリプトがあります。

```bash
npm run preview &            # http://localhost:4173
node tools/smoke.mjs         # 3 画面サイズで一周する
```

SwiftShader 上での FPS は性能評価には使えません。描画品質と性能は
GPU のある実機で確認してください。
