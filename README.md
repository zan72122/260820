# 地下ポンプ室 — 水を上まで届けよう

iPhone / iPad 向けのモバイル Web ゲームです。
高い塔のウォータースライダーは乾いています。その水がどこから来るのかを、
文章の説明なしに、地下の機械室で自分の指を使って見つけていきます。

対象は 4 歳児です。文字も数値も使いません。
弁を回す・呼び水を汲む・レバーを押す・分岐をタップする、この 4 つだけで
「下の水を、ぐるぐる回す機械で上まで送った」という因果が最後まで一続きに見えます。

## 動かす

```
npm install
npm run dev        # http://localhost:5173
npm run build      # 型検査 + production build
npm run preview
```

`?fast=1&px=0.35` を付けると、ソフトウェア WebGL の CI 用に解像度を落として起動します
（実機の描画には影響しません）。

## 遊びの流れ

1. 乾いた塔 → 地面の開口部を通って地下へ降りる（触れると短縮できます）
2. 青いハンドホイールを指で回す → サイトグラスに水が一筋入る
3. 呼び水ポンプを上下にスワイプ → ガラス管の気泡が減っていく
4. 保護カバーを開けて始動レバーを押し下げる → モーター、軸、インペラの順に動く
5. カメラが水の先端を追って上昇管を上り、開口部から地上へ抜ける
6. 塔の上の分岐弁を回す → その枝管の滑り台だけが濡れる
7. 水が滑り降り、プールに溜まり、同じ開口部を通って地下のタンクへ帰る

2 周目は 3 本の滑り台が選べます。2 本に分けると水が細くなるので、
地下へ戻って主弁をもう少し開く、という予測と検証が遊びになります。
星も通貨も経験値もありません。

## 構成

```
src/core/      ノイズ・PBR テクスチャのランタイム生成、マテリアル、レンダラと適応品質
src/sim/       配管グラフ（弁の開度・管ごとの充填率・移動する水前縁）
src/world/     機械室、塔と滑り台、部品ビルダー、配管ラン、水膜リボン
src/camera/    ショットの連鎖を管理するディレクター
src/interact/  画面座標のディスクで拾う寛容なタッチルーター
src/audio/     WebAudio による手続き的な空間音
src/ui/        文字を使わないヒントリングと 2 つの絵ボタン
scripts/       ヘッドレス Chromium での通し試遊とレイアウト確認
```

### 水の扱い

CFD は使いません。管ごとに `fill`（0–1）を持ち、弁の開度から求めた流量で先端が進みます。
ポンプの回転数・メーターの針・モーター音・水位はすべて同じ状態値から導かれるので、
見た目と音が食い違うことがありません。

長い配管は不透明のまま、シェーダで前縁より下だけを濡れた色・粗さに変え、
進行方向へ流れる細かなさざ波を乗せます。透明な水を丁寧に描くのは
サイトグラス・呼び水管・点検窓の中だけです。

### アセット

外部アセットはありません。PBR のカラー / ラフネス / ノーマルマップは
起動時に value noise から焼き、音は WebAudio で合成しています。
GLB・KTX2・Meshopt を導入する余地は残していますが、現状は不要です。

### 実機での確認

`node scripts/playtest.mjs portrait|landscape|phoneland` で、
起動から 2 周目までを実際のポインタ操作で通し、各場面を `shots/` に書き出します。
ソフトウェアラスタライザ上の frame rate は実機の指標にはならないため測定していません。
