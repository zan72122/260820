# ピクッ！ クイッ！ ウィーン！

4歳児がiPhone / iPadで遊べる、冬の湖のワカサギ釣りドーム船ゲーム。
文字の指示なし・一指操作だけで、

**トン、トン（誘う）→ 指を離す（静かにする）→ ピクッ（アタリ）→ クイッ（合わせ）→ ウィーン（電動リール）**

の固有動作鎖を繰り返します。

## 遊び方（すべて一指）

| 操作 | 意味 |
| --- | --- |
| 画面を短く上下スワイプ | 穂先を動かして誘う |
| 指を離す | 世界が静かになり、2〜4秒でアタリが来る |
| 穂先がピクッとしたら短く上へスワイプ | 合わせ |
| 大きな押し面を長押し | 電動リールで巻き上げ（離すと止まる） |
| 大きな絵ボタン | 餌を落として再開 |

一回目は水中のカットアウェイで「見えない魚が餌に触ると穂先が動く」因果を一つの連続空間で見せ、二回目は半分、三回目からは水中を見せません。釣れた魚は係員側の安全な取り込みで透明バケツに移り、泳ぎ続けます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型検査
npm run build      # 型検査 + production build
npm run preview    # dist配信
npm run e2e        # Chromiumスモーク（iPhone/iPad相当の縦横4画面で開始→再プレイまで）
```

`?e2e=1` を付けると決定的なアタリ時刻と検証フック `window.__game` が有効になります。

## 技術構成

- Vite + TypeScript + Three.js（WebGL 2）
- 穂先はdamped spring＋非一様曲げ（14関節・実テーパー形状）。船の低周波揺れと魚のbite impulseは別信号
- 糸は少数control pointのspline + screen-space幅のfat line（消えない糸）
- 水中カットアウェイはclipping planeで船体・水面を連続的に切る（暗転・別画面なし）
- 魚群はinstancing、餌に反応する個体のみCPU頂点ベンドの個別アニメーション
- 音はすべてWebAudio合成（環境音・ピクッ・クイッ・モーター・水音）
- DPR上限＋動的解像度で低性能機でも30fps以上を狙う
- 広告・課金・ログイン・得点・ランキングなし
