# モノレールをのせよう

4歳児向けの写実的3DモバイルWebゲーム。2台のクレーンで新造モノレール車体を吊り上げ、
軌道桁上に先に設置された台車へゆっくり降ろしてドッキングする——その一連の作業だけを磨いたゲームです。

実在の跨座式モノレール新車搬入工程(車体と台車の別搬入、台車の先行設置、
2台クレーンでの相吊り、慎重な降下ドッキング、車両移動機による検査場への移動)を、
架空の日本都市モノレールとして再現しています。

## 遊びかた

説明文はありません。一本指だけで遊びます。

1. **上げる** — 画面を上へスライド。たるんだワイヤーが張り、荷重が移り、車体が浮きます
2. **運ぶ** — 横へスライド。車体が軌道桁上の台車へ近づきます
3. **降ろす** — 下へスライド。最後の数十cmは自動で低速になり、位置が合ってドッキングします

着座後は自動で吊具が外れ、車両の灯りが初めて点き、車両移動機が検査場へ牽引します。
続いて次の車体が搬入され、何度でも繰り返せます。

## 開発

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # dist/ に静的ビルド
npm run typecheck
npm run e2e        # Playwright (Chromium) — 決定論的シムテスト
```

補助スクリプト(要 dev サーバー起動):

```bash
node scripts/shot.mjs <outdir>     # 各工程のスクリーンショット
node scripts/record.mjs <outdir>   # 縦横のプレイスルー録画 (webm)
node scripts/gesture.mjs           # 実ポインタージェスチャーでの通しテスト
node scripts/soak.mjs              # 20サイクル反復の健全性チェック
```

URLパラメータ: `?e2e=1`(決定論モード: RAFは描画のみ、シムは `window.__game.advance()` でのみ進行)、
`?nohint=1`(ジェスチャーヒント非表示)、`?seed=N`(ラウンド変化のシード)。

## 構成

- `src/sim.ts` — 状態機械(吊上げ→移動→降下→着座→荷重移行→吊具解放→牽引→次車両)と
  巻上げキネマティクス、減衰振子の揺れ、弾性域での荷重移行モデル
- `src/carbody.ts` / `src/bogie.ts` — 車体と跨座式台車(走行輪・案内輪・安定輪、空気ばね、中心ピン)
- `src/crane.ts` / `src/rigging.ts` — クレーンIK(旋回・起伏)、4本掛けフック、吊り天秤、張力で状態が変わるスリング
- `src/cameras.ts` — 4状態のカメラ演出(全体把握/重量把握/位置合わせ/着座)、縦横別経路
- `src/audio.ts` — 手続き生成のWebAudio(モーター、ワイヤー、警告音、着座音、金具音)
- `src/world.ts` / `src/props.ts` / `src/workers.ts` — 車両基地、トレーラー、車両移動機、作業員
