# レンコン水掘り — Lotus Root Water Digging

早朝のレンコン田。濁った水と泥の下に何があるのかは、水を当てるまで分かりません。

4歳児が iPhone / iPad の Safari で、指一本で遊べる写実寄りの 3D 収穫体験です。
WebGL 2 / Three.js / TypeScript / Vite。アセットのダウンロードは無く、空・泥・水・
レンコン・音はすべて手続き的に生成しています。

## 遊び方（文字は要りません）

1. 水面から出ている葉柄のうち、一本だけが水中から引かれるように傾きます。触ると
   作業者の手が泥へ入り、「この下のどこかにつながっている」という手掛かりだけを返します。
2. 画面を押している間だけホースから水が出ます。噴射点は指の **66px 上**に出るので、
   指が最初の発見を隠しません。
3. 泥がほどけると、白褐色の曲面が数センチだけ現れます。水を左右へ動かすと、節 →
   くびれ → 次の節、と輪郭が横へつながっていきます。
4. 露出したレンコンを触って上へなぞると、作業者がもう一方の手で下から支え、長い
   地下茎が泥から連続的に滑り出ます。速く操作しても折れません。
5. 水面近くで左右に振ると泥が落ちて白さが増し、収穫ボートへ運んで離すと収まります。
6. 直後に別の葉柄の周りへ小さな泡が上がります。メニューも採点も出ません。

右上の歯車で **音量 / ひかえめ（光・動き・粒子を弱く）/ かるく（負荷を下げる）**。
一本目を収穫すると左下に断面ボタンが出て、地下で節が横へ連なる様子を短く復習できます。

## 動かす

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build
npm run preview    # ビルド結果を配信（既定 4173）
```

同じ LAN の iPhone / iPad から `http://<PC の IP>:5173/` で実機確認できます。
音は WebAudio のため、最初のタップで有効になります。

## 検証

```bash
npm run preview
CHROME_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome node tests/play.mjs
```

iPhone 縦横 / iPad 縦横の 4 ビューポートで、起動 → 葉柄 → 噴射 → 露出 → 持ち上げ →
洗浄 → 収納 → 二本目 → 画面回転 → 断面までを自動で一周し、`test-results/` に各段階の
スクリーンショットと、露出率・洗浄率・掘削量・console エラーを出力します。
`node tests/shots.mjs` は 1 ビューポートだけの高速版です。

## 実装メモ

| 要素 | 方法 |
| --- | --- |
| 濁り | 水面板は薄い反射層。水中の物体側で深度に応じて silt 色へ寄せる（`MURK_GLSL`）。水を当てた場所だけ局所的に澄む |
| 泥除去 | プロットごとに 192² の RGBA マスク（R=除去量 / G=澄み / B=撹拌）。CPU 側にも同じ値を持ち、ベッドの頂点変位・法線・色と、レンコンの露出判定に同時に使う |
| 田の底 | 掘った穴が平らな田面に覆われないよう、田面シェーダはプロット矩形を `discard` する |
| レンコン | 節ごとの太さ差・くびれ・非円形断面・細根・枝分かれを spline に沿って生成。持ち上げは頂点ごとの遅延付き変位なので、瞬間移動せず端から滑り出る |
| 洗浄 | 長さ 64 の profile テクスチャに 澄み / 泥 / 濡れ を持たせ、掘削中は泥が 0.42 までしか落ちない（水中では粘土が付き直すため）。水上へ出してから初めて白くなる |
| 噴流 | tapered ribbon（ビルボード）＋少量の飛沫点。水面は局所へこみ＋リングリップル |
| 濁り雲 | 寿命 0.85〜1.3 秒の点群。下流へ流れて発見物を隠し続けない |
| カメラ | 自由視点なし。地下茎の走る向きから画角の方位を決め、縦画面ではさらに軸寄りへ回して節が斜めに写るようにする。主要点を安全枠に収めるまで自動で引く |
| 負荷 | 遠景葉 → 濁り粒子 → 波の細分 → 影解像度 → 内部解像度 の順に自動で落とす。シミュレーションは 1/32 秒固定ステップなので低フレームでも実時間で進む |

## 既知の制約

- 本格的な流体シミュレーションはしていません。泥は 2D マスク、水面は局所波シェーダです。
- WebGPU 専用機能は使っていません（ルールは WebGL 2 で完結します）。
- ヘッドレス Chromium（SwiftShader）での自動確認はソフトウェアラスタライズのため、
  フレームレートと最終的な見えの評価には使えません。実機／GPU のある環境で確認してください。
