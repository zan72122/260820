# 雲の結び目 (Cloud Knot)

モバイルSafari(iPhone / iPad)で遊べる短編3D Webゲーム。
雨の降らない尾根に一本の低い雲が引っ掛かり、その中心が結び目になって
固まっている。ユニコーンの螺旋角だけが、雲のねじれを感じ取り、
逆方向へ回してほどくことができる。

## 遊び方

- 画面をタップすると導入のカメラが進む
- 雲の輪の近くで指を置き、**結び目と反対方向(反時計回り)に円を描く**
- 四分の一回転ほどで輪が緩み、閉じ込められていた水滴が数滴だけ落ちる
- 円の大きさ・速さで、雨の広がりと強さが連続的に変わる
- 三つの輪をすべてほどくと、雲の帯を左右に動かして
  好きな場所へ雨を運べる。十分に遊ぶと太陽が戻り、雨の跡の上に淡い虹が出る

文字によるチュートリアルはない。ヒントは段階的な視覚表現のみ:
風に揺れる一本の蒸気筋 → 角への吸い付き → 輪の半回転の締め戻り →
ユニコーンの頭の傾き。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型検査
npm run build      # 本番ビルド
npm run test:e2e   # Chromiumスモーク(決定的、?e2e=1)
```

### テストフック

`?e2e=1` で決定的モード(固定シード、固定dt、DPR=1)。
`window.__game` に `phase / loops / rainLanded / flowersAwake / tick(s) /
unwind(i, amount) / loopScreen(i) / skipIntro()` を公開。
`?skip=1` で導入をスキップ。

## 技術構成

- TypeScript + Three.js + Vite
- 雲帯: スプライン沿いのリボンtube + カスタムシェーダー(風上→風下の流れ、
  結び目中心だけ凍結するスクロール、外縁の消散、下面の暗い厚み)
- 結び目の輪: トーラスリボン×3(ねじれ・ほどけ・弾みを頂点/フラグメントで変形)
- 内部水滴: instanced octahedra(光の粒、ほどき中は揺れる)
- 雨: 上限つきinstanced streak + ヒーロー水滴(最初の4滴はゆっくり落ちて視線を導く)
- 濡れ: ローカルマスクテクスチャ(地面の暗化と植生回復が同じマスクを参照)
- 植生: instanced草(個体差のある乾き・傾き) + CPU緩和で頭を起こす花
- ユニコーン: プリミティブ構成 + コード駆動ポーズ(接地、踏み替え、肩の張り)
- 音響: WebAudio手続き生成(風、結び目の低い張り、摩擦、雫、雨、遠い水路)
- 品質: 端末階層 + フレーム時間による内部解像度・スプライト数の自動調整
