# 分岐器 — 関節可撓式跨座型モノレール分岐器の3Dゲーム

4歳児が iPhone / iPad の縦・横画面で遊べる、文章なしのモバイルWebゲーム。
題材はひとつだけ：**巨大な軌道桁そのものが動いて道を作る、跨座型モノレールの関節可撓式分岐器**。

- 一本指で保守用操作盤のセレクターハンドルをスライドすると、
  リレー → ロック解除 → モーター・減速機 → 水平アーム → 台車走行 → 箱桁4本の関節転換 →
  案内面・安定面の連続変形 → 終端減速 → ロックシリンダ下降「カコン」→ 信号 → 列車通過、
  という因果連鎖が途切れないカメラで進む。
- 報酬・通貨・制限時間・ゲームオーバーなし。直線⇄曲線を何度でも切り替えて観察できる。

## 実行

```sh
npm install
npm run dev       # http://127.0.0.1:5183
npm run build     # 静的ビルド (dist/)
npm test          # Playwright E2E (Chromium)
```

クエリパラメータ: `?e2e=1`（決定論・音声off・DPR固定） `&fast=N`（シミュレーション倍速）。

## 構成

- `src/game/switchModel.ts` — 分岐器のキネマティクス（桁・関節・可撓曲線・駆動クランク・台車軌跡・走行経路を単一状態から生成）
- `src/world/` — 分岐器本体 / 環境 / 車両 / 操作盤（全ジオメトリ・テクスチャは手続き生成）
- `src/game/director.ts` — ステートマシン・連動・列車運行・段階ヒント・カメラ演出
- `src/core/` — 入力（全スワイプ＝作業入力）・合成音（WebAudio）
- `tests/e2e/` — 初回体験・誤操作・性能の自動検証
- `NOTES.md` — 資料との照合メモ（確認済み / 妥当な補間 / 演出上の簡略化）
