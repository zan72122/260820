# 長岡花火 最終章 ― 橋のナイアガラと正三尺玉

信濃川の夜。**下へ落ちる光の滝（長生橋のナイアガラ）** と **上へ昇って開く正三尺玉** が、
同じ川面の上で同時に起こる。その一枚の絵を作るための、独立した1章です。

モバイル web でそのまま動きます（ビルド不要・依存ゼロ・Canvas 2D）。

```bash
npm start          # http://localhost:5173/ を開く
npm run test:e2e   # Playwright スモーク（縦・横の2プロファイル）
```

`README.txt` 以外に既存の実装は無かったため、この章だけで完結する形で新規に作りました。
前章の正三尺玉／ナイアガラの資産は存在しないので再利用していません。

---

## この章がやろうとしていること

「花火が派手」ではなく、**方向の違う二つの巨大現象が同じ場所に共存する**ことを主役にしています。

| | 下向き | 上向き |
|---|---|---|
| 現象 | 橋ナイアガラ（全長 850m の火の滝） | 正三尺玉（開いて直径 約600m） |
| プレイヤーの操作 | ①「はしに ひを つける」 | ②「たまを うちあげる」 |
| 画面での役目 | 川面を金色に染める | 空を占める |

そしてこの二つは、**川面**で一枚に結ばれます。水面には滝の光の道と、開いた大玉の映り込みが
同時に載ります。章の到達点は「橋の光・上空の花火・川面の反射が一枚に収まる引きの絵」です。

## 遊び方（4歳児向けの二段階）

1. **はじめる** — 夜の長生橋が映る。
2. **はしに ひを つける** — 端から端へ火が走り、光の滝が落ち始める。
3. （サイレンと予告のあと）**たまを うちあげる** — 一発だけ、正三尺玉が昇って開く。
4. 余韻 → 結果 → **もういちど**

- ボタンは常にひとつだけ、画面下に大きく出ます。**画面のどこを触っても**同じように進みます（キーボードは Space / Enter）。
- タイミングは採点しますが、**失敗はありません**。少し早くても遅くても必ず成立します。
  ナイアガラは「玉が開いたあと」にしか消え始めないので、決定的な引きの絵は毎回必ず成立します。
- 何も押さずに 22 秒待つと自動で打ち上がります（行き止まりを作らないため）。

## カメラ演出

カットを作らず、ばね（クリティカルダンプ）で1本につないでいます。

| 段階 | やっていること |
|---|---|
| 導入 | 橋の手前側に寄って、トラスの骨格と川面を見せる |
| 点火 | 火の先頭に沿ってゆっくりパン。少し寄って「流れ」を感じさせる |
| 予告 | サイレンとともに空を開ける（あおりを上げ、視線を上へ引っ張る） |
| 昇り | 玉を追いながら、**開発の前に**引きの構図へ寄せていく |
| 開発 | 画面を切らない。空気が震える程度の短い揺れだけ |
| 引き | 橋の全長・大玉・水面の映り込みを一枚に収める |
| 余韻 | UI を消して、煙が流れるのをただ見せる |

引きの構図は固定値ではなく、「収めたい世界座標の集合」から毎フレーム焦点距離・カメラ位置・
あおりを解いています（`Camera#fit`）。縦画面でも横画面でも、橋の両端と大玉の上下左右が
必ず画面に入ります（`tests/smoke.spec.js` で検証）。

## 絵づくり

- **投影**: ヨーを持たないシフトレンズ型ピンホール。垂直線が常に垂直に写るので、
  橋の骨組みが建築夜景写真のように立ちます。水面 `Y=0` の鏡像は `(X, -Y, Z)` を
  そのまま投影するだけで物理的に正しい位置に出ます。
- **川**: 信濃川の夜は本当に黒い。まずその黒を描いてから、光だけを載せています。
  - 反射は「鏡像をぼかしたもの」ではなく、**鏡面反射点 d\* = D·h_cam/(h_cam+h_src) から
    手前へ伸びる光の道**として描いています。ナイアガラは点光源の帯ではなく
    850m の**線光源**として一枚の面で扱い、継ぎ目を出しません。
  - 上空の大玉は鏡面点が足元より手前に来るため、荒れた水面が手前いっぱいに
    にじませる別のモデルに切り替わります。
- **橋**: 長生橋の13連トラス（三角形が連なるシルエット）を手前面・奥面の2枚＋橋脚＋桁で
  組んでいます。夜の黒い骨組みは黒い川面に映っても見えないので、水面には**光だけ**を映します。
- **煙**: 自分では光らず、下（ナイアガラ）と上（開発）の光を受けて浮かびます。
  丸いふちが出ないよう、輪郭を落とした4種類の版を回転させて使っています。
- **遠景**: 東山連峰のシルエット、対岸の街あかり、水際の靄、地平の光害。
  待ち時間には遠くで別の花火が上がり続けます。
- **粒状感**: 空の階調にだけ薄くノイズを掛けてバンディングを消しています。

### 実測から意図的にずらしたところ

- **路面高 24m**（実際の長生橋はもっと低い）。引きの絵で「滝」が線に潰れず、
  4歳児にも「キラキラの滝」と分かるようにするための誇張です。
- **昇り 3.55 秒 / 開発高度 470m**。実物より速く低いですが、子どもの待ち時間として調整しました。
- 開発音は距離ぶん遅れて届きます（実際の 0.75 倍に圧縮）。

## モバイル対応

- `viewport-fit=cover` ＋ セーフエリア対応、縦横どちらでも遊べます。回転で構図を組み直します。
- 音は WebAudio の合成のみ（素材ファイル無し）。最初のタップで `resume()` します。右上でミュート。
- 品質は3段（high/mid/low）。`deviceMemory` / `hardwareConcurrency` / 画素数で初期値を決め、
  実測フレーム時間で自動昇降します。いちばん軽い設定でも重い端末は描画解像度自体を落とします。
- 反射パスは間引き（stride）＋尾なしで描き、負荷の山を作りません。

## 構成

```
index.html / styles.css      画面と大きなボタン
src/main.js                  起動・リサイズ・ループ・品質の自動調整・テスト用フック
src/chapter.js               章の進行（状態機械）とカメラ演出、描画の組み立て
src/camera.js                シフトレンズ投影・フレーミング解法・ばね追従
src/world.js                 長生橋と打ち上げ位置のジオメトリ（メートル）
src/fx/niagara.js            橋ナイアガラ（下向き）
src/fx/shell.js              正三尺玉（上向き・三重芯変化菊）
src/fx/particles.js          3D パーティクル（星は中心へ尾を引く）
src/fx/smoke.js              光を受ける煙
src/render/{sky,terrain,bridge,water}.js
src/audio.js                 WebAudio 合成（ざぁぁ／号砲／ヒュー／ドン）
scripts/serve.js             依存ゼロの静的サーバ
scripts/shots.mjs            開発用スクリーンショット採取
scripts/perf.mjs             実時間のフレーム時間計測
scripts/playthrough.mjs      実時間で通しプレイして要所を撮る
```

## デバッグ用のクエリ

| パラメータ | 意味 |
|---|---|
| `?fast=1` | RAF を止め、時間をテストから進める決定的モード |
| `?q=high\|mid\|low` | 品質を固定 |
| `?scale=1.5` | 描画解像度を上書き |

`window.__nagaoka` から `step(ms)` / `begin()` / `niagara()` / `shell()` / `state()` を呼べます。
