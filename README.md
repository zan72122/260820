# 長岡花火 ―― 正三尺玉

4歳児向けモバイル web ゲームの 1 チャプター。
信濃川の河川敷に立って、**サイレン → 点火 → 上昇 → 間 → 大開花 → 川面の余韻** という
正三尺玉の一連の感情だけを、自分の操作として体験する。

## 起動

```sh
node serve.mjs 8080      # または npm start
```

`http://localhost:8080/` を開く。iPhone / iPad から見るときは同じ Wi-Fi から
`http://<PCのIP>:8080/` を開く。ビルド不要・依存パッケージなし・外部素材なし。

## 遊びかた

1. 画面をタップして始める（ここで iOS の音が解禁される）
2. サイレンが鳴ったら、大きな「うちあげ」ボタンを **1回押す**（画面のどこでも可）
3. 玉が昇る。頂点で少し間があく
4. 「ひらけ！」を押すと開く。押さなくても 1.25 秒で必ず開く
5. 余韻のあと「もういちど」。色は毎回変わる（金・紅・青・緑の4種）

右上の 🔊 で消音。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面と UI |
| `css/style.css` | ボタン・字幕・セーフエリア |
| `js/audio.js` | WebAudio による合成音（サイレン・打上・上昇・開花・こだま・歓声・環境音） |
| `js/scene.js` | 夜の河川敷。遠景／水面／土手を一度だけオフスクリーンに焼いて毎フレーム転送 |
| `js/fireworks.js` | 玉と星。空気抵抗＋重力の解析解で動かし、燃えた軌跡そのものを尾に描く |
| `js/game.js` | 進行・カメラ・入力・負荷に応じた画質調整 |
| `serve.mjs` | 依存ゼロの静的サーバー（開発用） |

### 座標系

x は 0..1000 が基準画面幅、y は上が正で **y=0 が対岸の水際**。
カメラは「玉を画面のどの高さに置くか」と「引き」の 2 つで組み立てていて、
上昇中はその 2 つを同時に動かすことで、河川敷を画面下に残したまま玉だけが伸びていく。
開花高度は画面比から逆算するので、iPhone 縦・iPad・横画面のいずれでも
大輪と河川敷が同じ画面に収まる。
