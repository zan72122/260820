# SHADOW ALPHABET MACHINE

iPhone / iPad Safari で遊べる、4歳児向けの写実 3D 影文字ゲーム。

現代的な光学・展示設計工房が舞台。空間に離れて配置された黒染めの金属部品を、
減速機付きの手回しホイールで回転台ごと回すと、単一のスポットライトが乳白色
スクリーンへ落とす影が連続的に動き、正しい角度でだけ明瞭なアルファベットが
立ち上がる。

- **A** — 二本の斜材と一本の横材。回転台のみ。
- **Q** — 太いリングと斜めの短いロッド。回転台のみ、誘導を減らして。
- **H** — 二本の縦材と奥に離れた横材。回転台を合わせると背の高い垂直レバーが
  解錠され、ランプの高さで crossbar を中央へ導く。

完成後は前方向へスワイプで次の機械へ。H のあとは最初の機械へ戻り再プレイ。

## 光学的な正しさ

文字のストロークをスクリーン座標で定義し、光源からの光線に沿って **逆投影**
した位置に各部品を置く。したがって正解角の影は構成上厳密に文字になる。影は
毎フレーム実際の shadow map から得られ、部品を回せば影も連続的に動き、光源を
動かせば影の位置と形が変わる。スクリーンパネルだけは同じ投影行列・同じ
shadow map をサンプリングする専用シェーダで描画し、モバイルでも文字の
コントラストと輪郭が安定するようにしている(仕様で認められたハイブリッド)。

支持構造も投影計算に含まれる:

- **足柱** — ストローク下端から真下へ。影はスクリーン下端の外へ落ちる。
- **光線ストラット** — ストローク交点を通る光線に沿った連結棒。正解時の影は
  ストローク内の一点に潰れる。
- **隠し支柱** — H の crossbar を支える鉛直柱は、影が縦材ストロークの内側に
  重なる位置に置かれている(ランプ高さを変えても隠れたまま)。
- **影整列ブレース** — Q の tail を支える斜材は tail の光線平面内にあり、影は
  tail の延長線としてスクリーン外へ抜ける。

## 開発

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run typecheck
npm test           # Playwright smoke E2E (Chromium / SwiftShader)
npm run build      # 型検査 + production build (Q/H は非同期チャンク)
npm run preview    # dist を配信
```

`?e2e=1` で決定論モード(DPR1・intro スキップ・`window.__SAM__` フック)。
`tools/shot.mjs` は視覚検証用スクリーンショットツール。

## 構成

- `src/mathProj.ts` — 点光源の投影 / 逆投影
- `src/letters/{a,q,h}.ts` — 文字仕様(ストローク・奥行き・支持・detent)
- `src/station.ts` — 回転台・手回しホイール・リンク機構・ランプカート・
  レバー・機械式ストッパー・部品ビルダー・スクリーンシェーダ
- `src/environment.ts` — 工房(床レール・作業台・保管棚・窓・配管)
- `src/camera.ts` — 縦横別ポーズのカメラレール(操作中はカット無し)
- `src/game.ts` — 進行状態機械・ヒント・非同期文字ロード
- `src/audio.ts` — 手続き生成の機械音(ラチェット・detent・成功音)
