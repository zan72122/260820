# ゆきの したの かわ — 流雪溝あそび

雪国の細い道の下に隠れている「流雪溝」を、4歳ぐらいの子どもが一本指で遊べる
モバイル Web ゲームにしたものです。iPhone / iPad の Safari を想定しています。

**核になる驚きは二つだけです。**

1. 金属の蓋を持ち上げると、道の下に水が流れているのが見える。
2. 雪を入れると、その水が雪を運んでいってしまう。

失敗も、制限時間も、数字の UI も、長い説明もありません。

## あそびかた

1. 「あそぶ」を押す（この一回のタップで音が鳴るようになります）。
2. 光っている金属の蓋をタップする → 蓋が持ち上がり、手前の地面が切り取られて
   道路の断面と地下の水路が同時に見える構図に切り替わります。
3. 道に積もった雪の山を指でつまんで、穴の近くまでドラッグして放す。
   雪の山をポンと叩くだけでも、スコップが雪をすくって穴へ放り込みます。
   穴の近くで少し持っていても、勝手に落ちます。
4. 落ちた雪塊が水に飲まれ、くるくる回りながら崩れ、暗がりへ流れて消えます。
5. その投雪口のまわりの雪がなくなると蓋が閉まり、通りの下流にある次の投雪口へ。
   三つ終わると、また雪が積もって最初から遊べます。

右上のボタンは、音の入切と、はじめからやり直しです。

## うごかしかた

ビルド不要・依存パッケージのインストール不要です。静的ファイルを配信するだけ。

```sh
python3 -m http.server 8000
# → http://<PCのIPアドレス>:8000/ を iPhone / iPad の Safari で開く
```

ES modules を使うため `file://` では動きません。必ず HTTP で開いてください。

画像・音声のバイナリ素材は一つもありません。路面の凹凸はテクスチャと同じ高さ場から
頂点変位させているので、見えている轍と実際のジオメトリの凹凸が一致します。

## 地上と地下をどうつないでいるか

シーンは実寸のジオメトリで組んだ「通りの輪切り」です。地上の街並みを見せている間は
クリッピング平面を遠く（z = 20）に置いて何も切りません。蓋を開けた瞬間、その平面を
1.5 秒かけて側溝の位置（z = 2.10）まで動かします。手前側の地面・塀・家が順に切り取られ、
コンクリートの断面と地下の水路が現れて、道路面と水面が一画面に並びます。

そのため「雪をすくう」「穴に落とす」「水が運んでいく」が一度も画面から切れません。
カメラも同時に地面すれすれまで下りていきます。

## 対応と性能

- 一本指のみ。ピンチ・回転・二本指操作は使いません。
- 縦横どちらでも遊べます。回転すると構図（カメラ位置・注視点・画角）が組み直されます。
  画面が細長いときは画角を広げ、超横長のときは注視点を上げて主題を画面内に保ちます。
- `env(safe-area-inset-*)` でノッチとホームインジケータを避けています。
- 画素密度は最大 2 倍まで。フレームが落ちるときは自動で 1.5 → 1.15 倍に下げ、
  影の解像度も落とします。
- 描画負荷は三角形 3.4 万〜4.5 万、ドローコール 110〜230 程度（地上の街並みが軽く、
  地下断面＋雪塊が出ているときが重い側）です。

## 確認したこと

- 一周ぶんの通しテスト（`intro → 投雪口 3 つ → finale → 最初に戻る`）を、実際の
  `onDown / onMove / onUp` を叩いて自動実行し、状態遷移・蓋の開閉・断面への切り替え・
  雪の総量が保存されること・コンソールエラーがないことを確認しています。
- 画面まわりは iPhone / iPad 相当の viewport・DPR・タッチを与えた Chromium の
  デバイスエミュレーションで、縦横それぞれの構図と当たり判定を確認しました。
  **実機の iOS Safari で動かした確認ではありません。** 実機では特に、
  起動直後の音の解禁と、回転直後の再構図を見てください。
- 音は WebAudio の合成なので鳴らして聴く確認はできていません。AudioContext が
  `running` になること、例外が出ないことまでを自動で確認しています。
