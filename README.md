# こおりの みずうみ ― ワカサギ つり

4歳児が iPhone / iPad の指一本で遊べる、氷上ワカサギ釣りのモバイル Web ゲームです。
WebGL（three.js）による本物の 3D 空間 — 透視投影・遮蔽・視差 — で作っています。
CSS の擬似 3D は使っていません。

遊びの筋は一本です。

**氷に穴をあける → 黒い水が現れる → 糸を下ろす → 水の下の魚を見る → ぴくっときたら引く → 穴からワカサギがスポンと出る**

---

## 遊びかた

| 場面 | 操作 | 画面のことば |
| --- | --- | --- |
| 穴あけ | ハンドルのまわりを指でぐるぐる回す（ぐしゃぐしゃ動かすだけでも掘れます） | ぐるぐる まわそう！ |
| 氷くずすくい | 穴の上を指でなぞる | こおりを すくおう |
| 誘い | 上下にスワイプ | ゆらゆら して おさかなを よぼう |
| 合わせ | 上に引く（タップでも可） | きた！ ひっぱれ！ |

- 失敗はありません。時間切れも、ミスも、ゲームオーバーもありません。
- どの操作も一定時間で自動的に前に進むので、幼児が詰まることがありません。
- 魚の食いつき判定は非常に甘く、少し動かせば寄ってきます。
- 右上の `↻` で新しい穴を掘り直せます。`🔊` で消音。

## 起動

依存パッケージのインストールもビルドも不要です。静的ファイルを配信するだけで動きます。

```bash
# 例1: Python
python3 -m http.server 8000

# 例2: Node
npx http-server -p 8000 -c-1
```

ブラウザで `http://localhost:8000/` を開きます。
ES modules と import map を使っているため、`file://` では動きません（HTTP 配信が必要です）。

対応: iOS/iPadOS Safari 16.4+、Android Chrome、デスクトップの Chrome / Safari / Firefox。

### 開発用のクエリパラメータ

| パラメータ | 意味 |
| --- | --- |
| `?dpr=2` | 解像度の自動調整を止めて固定する |
| `?step=0.0166` | 実時間ではなく固定タイムステップで進める（自動テスト用に決定的になる） |

## 構成

```
index.html          エントリ。viewport / import map / UI オーバーレイ
css/style.css       UI レイヤーのみ（3D は全て WebGL）
js/main.js          状態機械・カメラ演出・全体の進行
js/world.js         雪原・氷盤・穴の内壁・黒い水・氷の裏側・粒子
js/sky.js           空のグラデーション、低い冬の日、三重の山並み、対岸の針葉樹
js/gear.js          アイスドリル・氷すくい・竿・仕掛け・バケツ
js/fish.js          ワカサギの手続き的モデルと、甘めの行動ロジック
js/fx.js            水紋・しぶき・氷片・泡・きらめき（プール管理）
js/line.js          スクリーン空間で一定太さに保つ釣糸
js/camera.js        ショット間を必ず「移動」でつなぐカメラリグ
js/input.js         指一本のジェスチャ（回転量・ドラッグ・スワイプ）
js/audio.js         WebAudio による全効果音の合成（音声ファイルなし）
js/textures.js      雪・氷・魚の肌・波紋法線などの手続き的テクスチャ
vendor/             three.js r185（MIT, vendor/THREE_LICENSE.txt）
```

外部アセットはゼロです。テクスチャも音も実行時に生成しているので、オフラインでも動きます。

## 設計メモ

**二層構造が主役。** 地上は静かで白く、水中は暗く青い。穴はその境目に開いた窓です。
氷は本当に厚み 20 cm の板としてモデリングしてあり、内壁も裏側も存在します。
水面は氷の上面より少し下 — 氷は浮いているので、実際に穴の水位は表面近くまで来ます —
そのおかげで穴が「井戸」ではなく「黒い円」に見えます。

**カメラは切らない。** 全ての場面転換は移動です。穴が開くと少し下がって水面を覗き込み、
糸に沿って穴を通り抜けて潜り、引き上げるときは同じ道を戻ります。
因果がつながって見えることを最優先にしています。

**釣糸はスクリーン空間で太さを保ちます。** 1px のラインは Retina では消え、
円柱は遠ざかると細くなります。どの深さでも見えるように、
クリップ空間で一定ピクセル幅に広げ、暗い縁取りと明るい芯の二重で描いています
（雪の上でも暗い水中でも見えます）。

**縦横比への対応。** 縦持ちでは画角を広げ、カメラをわずかに引きます。
安全領域（ノッチ / ホームインジケータ）は CSS の `env(safe-area-inset-*)` で避けています。

**性能。** 描画は 100 ドローコール以下、4〜5 万三角形。
フレーム時間を見て解像度（devicePixelRatio）だけを 1.0〜2.0 の間で自動調整し、
見た目の要素は削りません。
