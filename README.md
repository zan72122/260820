# ユニコーンの角修理工房

iPhone / iPad の Safari で遊べる、4歳児向けの短編3Dゲーム。
森の中の静かな修理工房で、ユニコーンの角の「光が途中で止まる」原因を
見つけ、洗い、埋め、硬め、磨いて、光を角の先まで通します。

## 遊びの中心

1. **謎** — ユニコーンが角の根元に光を集めるのに、光は途中で弱まり、
   角先はちらつき、壁のプリズムには途切れた色帯しか出ない。
2. **観察** — 検査灯を横に動かすと、角表面を走るハイライトが亀裂で
   途切れる。溝を伝う露の滴が、汚れた場所で止まる。
3. **理解** — 溝を数センチ洗うと、**洗った距離だけ**露と光が先へ進み、
   まだ汚れている場所でまた止まる。「そういうことか」の瞬間。
4. **修理** — 亀裂に月樹脂を流し込み(毛細管のように奥へ進む)、
   窓の日光を小さな鏡で導いて硬化させ、布で螺旋に沿って磨く。
5. **試験と自由** — 白い光が角先から出てプリズムで分かれ、壁に
   スペクトルが現れる。プリズムを滑らせ、角を少し向け、磨きを重ね、
   鏡で光量を変えると、色帯は連続的に応える。失敗は存在しない。

再プレイでは亀裂の位置と汚れの詰まり方が変わりますが、
因果の法則は毎回同じです。点数・制限時間・文字はありません。

## 技術

- Vite + TypeScript + three.js。外部アセットなし(全て手続き生成)。
- 角: 螺旋溝を実ジオメトリで彫ったコーン+カスタムシェーダ。
  汚れ/研磨は t 軸1Dステート、亀裂はパラメトリック(充填・硬化・
  余剰・平滑の進行)、内部光は根元→先端の emissive 前線。
- 光の前線・露の滴・壁のスペクトルは同一の因果計算
  (`computeLightFront`)を共有。
- ユニコーン: ポニーの頭蓋比率で断面ロフトした頭部・首・伏せた胴体。
  たてがみは制御された彫刻ロック(毛物理なし)。
- 工房: 機能の読める道具のみ(支持台、検査灯、刷毛、水洗ノズル+
  フラスコ+ホース、樹脂シリンジ、研磨布、反射鏡、石英プリズム、
  排水トレー)。
- モバイル: DPR上限2+動的解像度、影は太陽1灯1024、WebGL2で動作。

## 開発

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 型検査 + プロダクションビルド
npm run test:e2e   # Playwright スモーク(実ジェスチャで一周)
```

`?seed=N` で故障レイアウトを固定、`?e2e=1` でテスト用の決定論モード
(3倍速・音なし・DPR1・`window.__uha` フック)になります。

`scripts/shot.mjs` は開発用のプレイ進行+スクリーンショット採取
ヘルパーです(`PORTRAIT=1` で縦画面)。
