# ボウリング — Switch Sports風 3Dゲーム

Three.js + Rapier によるWebGLボウリング。実在のボウリングセンターを資料とした
実寸・実材質・実照明のレーン環境で、マウススイングによる10フレーム制の
1人プレイができます。

![screenshot](docs/screenshot.png)

## 操作

- **狙い**: ドラッグ中に左右へ動かすと立ち位置（ボール位置）が動く
- **投球**: ボールを手前に引いてから前へ振り抜いてリリース
  - 振りの速さ → 球速（最大 9.5 m/s）
  - リリースの横方向 → 投球角
  - ストロークを横に払う（軌跡を曲げる）→ フック回転（回転軸の傾き）
- ゲーム終了後はクリックで新しいゲーム

## 起動

```bash
npm install
npm run dev        # http://localhost:5173
```

URLパラメータ:

- `?fast=1` — E2E/CI用プロファイル。低解像度・影/クリアコートオフ・
  自動シミュレーション停止（テストが `window.__game.advance()` で論理時間を進める）
- `?seed=N` — 摩耗・汚れ・木目など手続き生成のシード（既定 20260821）
- `?cam=x,y,z,tx,ty,tz` — デバッグ用固定カメラ（任意アングルの検証）

## 検証

CLAUDE.md の検証順に従う:

```bash
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
npm run test       # Vitest（スコアリング全パターン / スイング写像 / 物理決定論）
npm run e2e        # Playwright Chromiumスモーク（workers=1, retries=1, maxFailures=1）
```

E2Eは `?fast=1&seed=42` で起動し、`window.__game` の決定論APIで投球を注入して
論理時間を直接進める。FPS・見た目の最終品質はSwiftShader環境では判定しない。

## 実装の骨子

- **寸法**: USBC規格に準拠（`src/util/units.ts`）。レーン幅41.5in・39枚板、
  ファウルライン→1番ピン60ft、ガター9.3125in×1.875in、ピン15in/1.58kg
  （回転体プロファイルから質量・重心・慣性を数値積分）、ボール8.5in/6.8kg
- **物理** (`src/physics/`): Rapier固定Δt=1/120。フックは台本ではなく、
  ハウスショットのオイルマップ μ(x,z) を毎ステップボールの接触摩擦へ書き込み、
  回転軸の傾き×バックエンドのドライ摩擦から創発させる
- **ビジュアル** (`src/scene/`, `src/textures/`): 全テクスチャはシード付き
  Canvas手続き生成。摩耗・汚れは使われ方由来（右投げのボールトラック帯、
  スライド足の擦過、ピン腹の被弾帯、赤帯の縁欠け）で、対称・一様にしない。
  指穴はCSGによる実ジオメトリ。照明は実在光源のみ（天井トロファー・
  ピンデッキ灯）で、発光縁・ネオン・DoFボケは使わない
- **奥行き**: 近景（ボール・アプローチ・ボールリターン）/ 中景（レーン・
  隣接レーン）/ 遠景（ピンデッキ・マスキング・奥壁）を、照度勾配・
  ごく薄い指数フォグ・シルエットで分離
- **スコア** (`src/game/scoring.ts`): 正規ルール（ストライク/スペア/10フレーム目3投）。
  デッドウッド撤去時、立ちピンは実機のピンセッター同様に現位置へ残す

## 構成

```
  core/engine.ts      描画と固定Δtループ（fastモードで手動シミュレーション）

  scene/              レーン / ピン / ボール / 環境 / 照明 / カメラ
  textures/           手続きテクスチャ（木目・オイル・摩耗・塗装・カーペット）

  ui/hud.ts           スコアカードHUD
tests/unit            Vitest
tests/e2e             Playwrightスモーク
```
