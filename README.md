# みずをためて、コン――ししおどしの庭

4歳児向けの、日本庭園の添水（ししおどし）を触るモバイルWebゲーム。
音楽は流れない。水、竹、石、庭の残響だけで状態を伝える。

## 遊び方

庭は静かで、竹筒は空のまま始まる。上流の水路には水が一滴たまり、
木製水門の隙間で竹筒の方向へ揺れている。
その水門を **横へスワイプ** すると、木の擦れる音とともに水路が開く。

あとは待つだけでいい。

    ちょろちょろ → コポ → 軸のキュッ → ゴクン → ザバッ → コン → 余韻 → 静けさ

水門の開度を変えると、水筋の太さ、飛沫、流音、竹筒が満ちる速度、
そして「コン」と鳴るまでの間隔が同時に変わる。
三周期鳴らすと、長さの違う二本目の添水と、流量を分ける仕切り板が現れる。
仕切り板も指でつまんで動かせる（水門と仕切り板のうち、指に近いほうを掴む）。

得点も、合わせるべき拍もない。「次はいつ傾くか」を予測することが遊びになっている。

画面右上の丸いボタンで、音量・ミュート・「静かな音」を切り替えられる。設定は端末に残る。

## 起動

    npm install
    npm run dev       # 開発サーバ（--host 付き。実機は同一LANのIPで開く）
    npm run build     # 型検査 + production build（dist/）
    npm run preview   # dist/ を配信して実機確認

対象は iPhone / iPad の Safari、縦横両対応。
既定は WebGL 2。`?renderer=webgpu` を付けたときだけ WebGPURenderer を試み、
初期化に失敗すれば必ず WebGL 2 へ戻る（`src/scene/renderer.ts`）。

## 仕組み

### 決定論的シミュレーション（`src/sim/`）

固定刻み 1/180 秒。支点まわりのモーメントだけで一周期が生まれる。

    τ = g·cosθ·( m_water·d_water(θ) − m_tube·d_tail ) − c·ω − μ·N·tanh(45ω)
    d_water(θ) = d0 + 0.40·(θ − θ_rest)

傾くほど水が口側へ寄って **てこが伸びる**。これが正のフィードバックになり、
閾値の手前ではほとんど動かず、越えた瞬間に一気に反転する。
排水は角度と水量から、衝突速度は角速度から決まる。
竹の長さ（0.64 m と 0.47 m）で質量・慣性・てこが一括に縮尺され、
二本は違う間隔で、違う余韻で鳴る。

`dt` は 0.05 秒で頭打ちにし、蓄積器も 0.25 秒で切る。
復帰直後に周期が早送りされることも、二重に走ることもない。

### 音響（`src/audio/`）

すべて起動時に合成し、AudioBuffer へ焼いてから遊びが始まる（読み込み待ちがない）。
最初の水門操作で AudioContext を resume する。実録音を使う場合も、
`bank.ts` の同じキーへ差し替えれば他は変えなくてよい。

| 層 | 内容 | 駆動する状態 |
|---|---|---|
| Water source | 水路（細流・太流・奔流の等出力crossfade）、入口の滴、筒内部、排水、鉢の飛沫 | `flowRate` `inflow` `dumpRate` `basinFlow` |
| Bamboo mechanism | 軸の摩擦、筒内の空洞共鳴、衝突後の微振動 | `angularVelocity` `pivotLoad` `fillRatio` `resonanceDecay` |
| Stone | 接触トランジェント、鈍い高域、石面からの短い反射 | `impactVelocity` `wetness` 打点 |
| Garden | 葉擦れ、風、遠い鳥（余韻中は鳴らさない） | `inAfterglow` |

- 竹筒が満ちるにつれ、内部の水音と空洞共鳴の比率が穏やかに移る。共鳴帯域は
  残った気柱の長さから 175–350 Hz の範囲でゆっくり動くだけで、音階にはならない。
- 「コン」は竹の曲げモード（非調和列）＋気柱＋石の高域＋接触トランジェントの合成。
  竹ごとに5種類を用意し、打点・含水・速度・再生レートで毎回変える。
  連打が続くと僅かに音量を戻し、20周期聞いても疲れないようにしてある。
- 中域（約1.1 kHz）を持ち上げ、90 Hz 以下を落としてある。iPhoneスピーカーで
  低域が消えても、竹と石の当たりは識別できる。
- 庭の空間は 0.85 秒の短いIR（初期反射＋拡散尾部）による畳み込み。長い残響は使わない。
- 衝突音は映像より前に鳴らない。事象は物理と同じフレームで発火し、
  次の提示に合わせて 18 ms 遅らせて鳴る。

### 木製水門の抵抗（`src/sim/physics.ts` / `src/input/pointer.ts`）

指の位置と板の位置の差を「木部のたわみ」として保持する。
開度20%までは静止摩擦を大きく取り、たわみが閾値を越えるまで板は動かない。
その間、板は指の方向へわずかに傾き、擦れ音が強くなる。
越えると板が指へ追いつく。入力遅延ではなく、物理的な抵抗として見せている。

### 描画（`src/scene/`）

外部アセットを持たず、材質テクスチャ（色・粗さ・法線）を同じ高さ場から手続き生成する。

- 竹：節のふくらみ、肉厚、縦の繊維、口の斜め切断、内部の空洞、末端の節、支点付近の摩耗
- 支点：二本の柱・楔・回転軸。接触位置が構造として説明できる
- 石：ひとつずつ違う形。衝突石は接地と質量を持ち、打点に軽い摩耗
- 水鉢：縁の厚み、深さ、陰側にだけ苔
- 苔：面を覆わず、湿潤域・日陰・石の凹部に限る
- 土：粒径、湿り、落ち葉、踏み固めの差
- 近景＝竹筒・水門・水滴・衝突石／中景＝水鉢・支持構造・石・下草／遠景＝小径・垣・樹木・建物
- 朝または曇天後の柔らかい自然光。逆光で前景の薄い葉に透過光が出る。発光縁は使わない

竹筒は半透明にしない。**最初の一周期だけ**、隅に短い断面（カットアウェイ）が出て
内部水位を見せ、以後は水音・筒の沈み・滴の位置から状態を読む。

### 画面

- 縦：水路が上、竹が中、石が下に積み上がる
- 横：ほぼ真横から、流れと傾きを同時に見せる
- 回転しても水量・竹筒角度・周期数はそのまま（シミュレーションは向きを知らない）
- 一周期目の途中でカメラを切り替えない。二本目が出たときだけ、ゆっくり画角を広げる

## 構成

    src/
      main.ts              起動、ループ、復帰処理、断面の合成描画
      sim/state.ts         共有状態（映像と音はここだけを読む）
      sim/physics.ts       剛体・流量・排水・衝突・水門の静止摩擦
      audio/dsp.ts         Biquad、モード加算、ループの継ぎ目消し
      audio/bank.ts        全音源の合成（差し替え点）
      audio/engine.ts      バス構成、連続層、事象の発火
      scene/renderer.ts    WebGL 2 / WebGPU の選択と環境マップ
      scene/textures.ts    材質テクスチャの手続き生成
      scene/geom.ts        竹稈・石・水鉢・樋・葉のジオメトリ
      scene/water.ts       水筋・飛沫・波紋
      scene/world.ts       庭の組み立てとカメラ
      scene/cutaway.ts     最初の一周期だけの断面
      input/pointer.ts     一指の掴みとスワイプ
      ui/hud.ts            音の設定と子ども文
