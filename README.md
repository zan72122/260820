# ぶたいそで

4さいのための、モバイルWeb 3Dゲーム。

くらい ぶたいそでで まつ。まくの むこうを のぞく。せんせいの あいずで、
あかるい ぶたいへ でる。

---

## このゲームの主役

おゆうぎ会の主役は、ふつう舞台の上の子です。このゲームは違います。

**暗く狭い舞台袖から、明るく広い舞台と大量の観客へ、自分の操作で境界を越える瞬間**
——それだけを作りました。踊りません。得点もありません。一周2〜3分です。

固有動作鎖はこの一本だけです。

```
暗い舞台袖で待つ
  → 袖幕から舞台を少し覗く
  → 先生から「まだだよ」という非言語的な合図
  → 前の演目が終わる
  → 先生が「今だよ」と合図
  → 緞帳が開く
  → 舞台袖から明るい舞台へ出る
  → 客席が一気に視界へ現れる
```

## 説明文を一切出さない設計

起動直後、プレイヤーは暗い舞台袖に立っています。見えるのは赤い袖幕、
幕の隙間から漏れて**揺れている**光、床のビニールテープ、衣装を着た子どもたち、
舞台の方を気にしている先生だけ。何をすべきかは書かれていません。

代わりに、2〜3秒後に**他の子が一瞬だけ幕を覗いて戻ります**。先生の視線は
袖幕とプレイヤーの間を往復します。それだけが手掛かりです。

幕を横へドラッグすると10〜20cmだけ開き、舞台と客席がちらっと見えます。
初回のみ、先生が振り向いて**手のひらを下へ向けて二度なでる**——「まだだよ」。
失敗ではありません。幕は柔らかく戻ります。

やがて前の演目が終わり、拍手が起き、緞帳が閉まり、一瞬静かになります。
先生が**しゃがんで目線を合わせ、片手を舞台側へ開きます**——「今だよ」。

言葉は一つも使っていません。指示矢印もありません。

### ヒントの段階

数秒操作がない場合のみ、この順でだけ強くなります。

| 段階 | 待ち時間 | 内容 |
|---|---|---|
| 1 | 4.5秒 | 先生の視線がプレイヤーで止まる |
| 2 | 9秒 | 他の子が実際にやってみせる |
| 3 | 15秒 | 画面内の手が一度だけ身振りを見せる（1セッション1回きり） |

色付き矢印や文章チュートリアルは、どの段階にも存在しません。

## 操作

**一指だけ**です。ピンチも二指回転も仮想スティックもありません。

- **袖幕を横へドラッグ** → 覗く
- **舞台方向へスワイプ**（または幕を大きく開ける、または画面をタップ）→ 出る

最初に引いた向きが「開く」向きになります。4歳児に方向の規約を当てさせません。
反応点は画面全体なので、指が幕そのものを隠すことがありません。
布とキャラクターの反応はポインタイベントと同じフレームで始まります。

## カメラ

プレイヤーはカメラを操作しません。カメラは演出装置です。

- **待機**：床から0.94mの幼児目線。近景に袖幕の布、中景に先生と子ども、遠景に漏れる光の3/4構図。
- **覗く**：引いた量に合わせてカメラが幕へ寄り、数cm横へずれる。隙間は常に画面中央に保たれ、広がるのは**隙間の向こう**だけ。舞台床→照明→客席が段階的に見えます。
- **登場**：カメラは子どもと**同じ経路**を一定距離あとから歩きます。だから子どもが通れる隙間はレンズも通れて、袖幕が近景を横切ります。カット無し、急旋回無し。
- **客席Reveal**：脚本ではなく幾何で起きます。子どもがプロセニアムの袖柱を物理的に越えたので、部屋がそこにあるだけです。その後カメラはゆっくり後方へ引き、視野が広がります。

縦画面と横画面で構図の狙いを変えています（横は袖幕の端の外が見えないよう視線を袖寄りに、
縦は床とテープが入るよう俯角を浅く）。リプレイUIは主要対象に重ならない位置に置いています。

## 技術

TypeScript + three.js。**追加アセットはゼロ**です。

### レンダラ

`WebGPURenderer` 一本。WebGPUがあれば（Safari 26+ の iOS/iPadOS）WebGPUで、
無ければ同じレンダラのWebGL2バックエンドで動きます。シーングラフは共通なので、
看板体験がバックエンドに依存しません。初期化に失敗した場合はcanvasを作り直して
WebGL2で再試行します。

### 布

袖幕はソルバを使いません。プリーツ・振り子・たくし上げは
`(u, v, gather, time)` の閉形式なので、頂点バッファへ直接評価します。
1枚あたり約1.2k頂点で固定、モバイルでも挙動が完全に決まり、それでいて
「たくし上げると布の行き場が無くなってプリーツが深くなる」ので厚手の重量感が出ます。
自由端には厚みのストリップを別に張っています。

### 素材

テクスチャは全て起動時に描画します（glTFもKTX2も音声ファイルも配信しません）。
描画予算はHero Materialsに集中しています。

1. 赤い厚手の舞台幕（sheen付きベルベット、縫い目、裾の毛羽立ち）
2. ワックスのかかった木製舞台床（clearcoat、木目、擦り傷）
3. 衣装のサテン／不織布
4. 金属製舞台照明器具

それ以外は素のstandard materialです。緞帳は同じ布を色違いで共有し、
512×512のセットを二度焼かないようにしています。値ノイズの整数ハッシュ化と
合わせて、全テクスチャの生成は約0.5秒です。

### 照明

実際の劇場的な露出差（舞台袖=低照度／舞台=暖色スポット／客席=暗いが人が読める）を
トーンマッピング露出ごと状態で切り替えます。暗部は潰しません。

**動的シャドウを落とすライトは常に1灯だけ**で、プレイヤーが見ている対象を追います。
それ以外は影を落としません。ポストプロセスは使わず、ビネットはCSSです。

### アダプティブクオリティ

フレーム時間を監視して、内部解像度 → 影 → 付加要素の順に段階的に落とします。
内部ピクセル数は devicePixelRatio をそのまま使わず、約2.6メガピクセルで頭打ちにします。
豪華な30fpsより、安定したフレームペーシングを優先します。

### 音

Web Audio APIで全て合成しています。

```
[幕の向こうバス] → lowpass → gain ─┐
[手元バス]                        ├→ dry ─→ comp → out
                                  └→ send → convolver → wet ─┘
```

前の演目の音・拍手・客席のざわめきは lowpass 620Hz の向こう側にいます。
舞台へ出る瞬間、このカットオフを15kHzまで開き、リバーブ送りを上げ、
部屋を広げます。「狭い裏側→広い表舞台」の音響的Revealが、
録音の差し替えではなく実際のフィルタ移動として起きます。

先生の声は言葉ではありません。2つのフォルマントを持つ短い母音です。
台詞を作らずに「やさしい大人が今なにか言った」だけを伝えます。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果を 4173 で配信
```

### 検証

```bash
npm run preview &
npm run verify                     # 一周分の振る舞いを21項目チェック
npm run shoot -- --device=ipad     # 全フェーズのスクリーンショット
npm run frame -- --peek=1          # 単発の構図確認
```

`tools/verify.mjs` は実際の一指ジェスチャでゲームを最後まで動かし、
覗きが10〜20cmに収まること、どちら向きのドラッグでも開くこと、
「まだ」が失敗状態にならないこと、Revealが完走すること、
2周目が正しくリセットされることなどを確認します。

コンテナ内はソフトウェアラスタライズなので、**このツールのフレームレートは
実機の指標になりません**（構図・状態遷移・正しさのみが有効です）。
ゲーム時間の進行には固定ステップの `window.__butai.tick(seconds)` を使います。

### URLフラグ

| フラグ | 効果 |
|---|---|
| `?fast=1` | 決定論的なシード、小さいテクスチャ、テスト用フック有効 |
| `?gl=1` | WebGPUがある環境でもWebGL2バックエンドを強制 |
| `?quality=low\|mid\|high` | アダプティブクオリティを固定 |
| `?seed=N` | 周回ごとの変化を固定 |

## 意図的に入れていないもの

ダンス、長い劇、着せ替え、得点、コイン、進行度バー、実績、
チュートリアル文、矢印、音声ナレーション。

主役は常に、**「幕の向こうを知りたい」→「合図の意味が分かった」→
「自分からもう一度舞台へ出たい」** だけです。
