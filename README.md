# ラムネ

iPhone / iPad の Safari で、4 歳児が指一本で遊ぶ写実 3D の玩具。

遊びの中心は飲み物ではなく、ラムネ瓶だけが持っている一瞬の物理事件です。

    押す → ビー玉が栓から外れる → ガラスの中へポンと落ちる → 炭酸が一斉に立ち上がる

開栓後は第二の遊びへ続きます。

    傾ける → ビー玉が瓶首を転がる → くぼみに収まる → なめらかに注げる
                                 → 傾けすぎるとビー玉が瓶口へ転がり、コトンと流れが止まる

## 動かす

ビルド不要です。静的ファイルを配信するだけで動きます。

    python3 -m http.server 8080
    # → http://localhost:8080/

`file://` では ES modules が読めないので、必ず HTTP で開いてください。

## 操作

| 場面 | 操作 |
| --- | --- |
| 開栓前 | 画面のどこかに触れる → 玉押しの芯が瓶口へ合い、カメラが首へ寄る |
| 開栓 | そのまま下へ drag、または押したまま待つ |
| 開栓後 | 左右へ drag して瓶を傾ける |
| 次の一本 | 一杯注ぎ終われば自動。氷のたらいを軽く叩いてもよい |

文字による説明は一切出しません。無操作が続くと玉押しがそっと弾み、瓶口がほのかに光ります。

## URL パラメータ

| パラメータ | 意味 |
| --- | --- |
| `?tier=low\|mid\|high` | 描画予算を固定する（既定は端末から推定） |
| `?fast=1` | 低負荷モード。DPR 1、影・粒子を削る |
| `?manual=1` | RAF を止め、`window.__ramune.step(秒)` でテストが論理時間を進める |
| `?variant=0..3` | 瓶の個体（ガラス色・ビー玉色）を固定する |

## 構成

    index.html            画面。メニューは出さず、いきなり瓶が映る
    src/profile.js        瓶の断面プロファイル。メッシュ・物理・液量が共有する唯一の定義
    src/marblePhysics.js  ビー玉の物理（瓶ローカル XY 断面の円 vs 多角形）
    src/bottle.js         瓶。ガラス / 液体 / ビー玉 / 結露 / 泡
    src/bubbles.js        炭酸。位置は全部 GPU 側で計算する
    src/world.js          縁台・氷のたらい・砕氷・コップ・遠景・光・注ぐ流れ
    src/pusher.js         玉押し
    src/director.js       進行と演出。状態機械とカメラ
    src/env.js            手続き生成の環境マップ（PMREM）
    src/textures.js       手続き生成テクスチャ（外部画像 0 枚）
    src/audio.js          効果音。全部 WebAudio の合成音（音声ファイル 0 個）
    src/input.js          一本指の入力
    src/quality.js        端末別の描画予算
    vendor/three/         three.js r185（MIT）

外部アセットをひとつも読み込まないので、初回表示は three.js の 1 リクエストだけで済みます。

## 設計上の判断

**厚いガラスに transmission を使っていません。** モバイルでの負荷が重いうえ、
瓶の中に液体とビー玉と泡が入れ子で入るため、屈折の入れ子はどのみち破綻します。
代わりに、視線と法線のなす角から「光がガラスの中を通る距離」を近似して、
縁に向かって色が濃く・不透明になるようにしています。さらに手前のガラスと
奥のガラスを別メッシュに分け、その間に中身を挟んで描くことで、
「厚いガラスの中にものが入っている」という読み取りを成立させています。
氷とコップも同じモデルを共有しています。

**ビー玉の挙動は演出ではなく物理です。** 瓶の内壁プロファイルから 2D の
多角形を作り、円との衝突を解いています。瓶首のくぼみがビー玉を保持するのも、
傾けすぎるとくぼみを乗り越えて瓶口を塞ぐのも、当たり判定の結果として
自然に出てくるもので、角度のしきい値を書いた場所はどこにもありません。
音も接触イベントから直接鳴らしているので、映像と必ず同期します。

**傾けの回転軸を瓶の首に置いています。** 実際に手で注ぐときもそこを持ちますし、
何より、傾けてもビー玉と瓶口が画面の同じ場所に留まるので、
「傾ける → ビー玉が転がる → 流れが変わる」が一目で読めます。

**未開栓の瓶は炭酸圧で満たされていて、液面がビー玉の底に触れています。**
開栓すると圧が抜けて泡が口から少し逃げ、液面が細い首の中をすっと下がります。
細い首では、わずか 8mL の増減が 3cm の液面移動になります。
これが「開いた」という状態変化のいちばん分かりやすい合図です。
