# パカッ！ ひみつのジオード

泥だらけの石を洗って、そっと割って、なかの結晶を光にかざす —— iPhone / iPad の
Safari で遊べる一本指のブラウザゲームです。文字は読めなくてもかまいません。

## 遊びかた（説明は要りません）

1. **あらう** — 指でこすると泥が落ち、石がぬれて光りはじめます。こすると石は指の下で
   まわるので、こすりつづけるだけで反対側の泥にもとどきます。
2. **おく** — きれいになった石を、右の台へはこびます。
3. **わる** — くさびをタップします。三回めで「パキッ」と割れ、すきまから色のついた光が
   もれます。
4. **ひらく** — フタを上へドラッグして、大きくひらきます。
5. **はらう** — ブラシで結晶の粉をはらうと、結晶がきらめきはじめます。
6. **かざす** — 石を持ちあげると、窓の光がとおって、机と壁に色のもようがゆれます。
7. **かざる** — ビロードの台へおくと、部屋が暗くなって結晶だけが光ります。

最後に、絵だけの三つのボタンが出ます — おなじ石をもう一度 / ちがう石 / あつめた石。

## 起動

```bash
npm install
npm run dev          # http://localhost:5173  (--host なので実機からも見られます)
npm run build        # 型チェック + 本番ビルド -> dist/
npm run preview      # ビルド結果を配信
```

実機で試すときは `npm run dev` の表示する LAN アドレスを iPhone の Safari で開いて
ください。ホーム画面に追加すると全画面で起動します。

### URL パラメータ

| パラメータ | 効果 |
| --- | --- |
| `?seed=12345` / `?seed=amethyst` | 石を固定します。同じ seed なら毎回おなじ石 |
| `?q=low` \| `mid` \| `high` | 画質段を固定します（既定は端末から推定） |
| `?fast=1` | E2E 用。DPR 1、ブルームと火花を切り、形状を粗くします |

## 検証

```bash
npm run lint         # ESLint
npm run typecheck    # tsc --noEmit
npm test             # Vitest（純粋ロジック）
npm run e2e          # Playwright / Chromium スモーク
```

`window.__GEODE__` に自動テスト用の API を公開しています
（`step` / `mud` / `powder` / `rub()` / `tap()` / `drag()` / `frames()` など）。

## 実装メモ

- **Three.js r185 / WebGL2**。追加のアセットは一切ありません（画像・音・フォントすべて
  実行時生成）。初回ロードは JS 約 190 KB gzip のみです。
- **主役材質はすべてフラグメントシェーダで手続き生成**しています。割れる瞬間にカメラが
  極端に寄るため、焼き込みテクスチャでは解像度が破綻します。3D ノイズなら距離に関係なく
  ディテールが保ち、テクスチャメモリもほぼ消費しません。
- **泥・ぬれ・粉は指で塗るマスク**です。ジオードは UV 展開していません。シェーダと
  CPU 側が同じ equirect / disc 射影を共有するので、触った場所がそのまま落ちます。
- **上下の殻は共通の割れ面プロファイルから生成**しているので、閉じたときに必ず噛み合い
  ます（`src/test/geode.spec.ts` で検証）。
- **カメラはプレイヤーに渡しません**。場面ごとにショットが決まっていて、いちばん寄るのは
  「最初のすきまから光がもれる瞬間」です。
- **音は WebAudio で合成**しています。こする音と、くさびがきしむ音は指に追従する連続音です。
- **画質は三段**（low / mid / high）で、フレーム時間を見て一度だけ落とします。

詳しい設計判断は `docs/design.md` にあります。
