# ユニコーンと虹糸の橋

雨上がりの高地。雨粒から引き出せる「虹糸」を角に巻き取り、
岩の裂け目に橋を織って、ユニコーンが向こう岸へ渡る——
4歳の子どもがiPhone / iPadのブラウザで遊べる縦型3D体験です。

文字も点数も制限時間もありません。世界の規則はひとつだけ:

> 雨上がりの特定の角度で分光された光は、細い張力を持つ「虹糸」として雨粒から引き出せる。

## 遊びかた

1. 雨粒から垂れる細い光に、指で角先を近づける — 糸が角に掛かる
2. 指で円を描く — 頭が回り、糸が雨粒から角の螺旋に巻き取られる
   - ゆっくり回すと密に、速く回すと波打って巻かれる
   - 逆回転で一周ずつほどける(雨粒に戻る)
   - 集める順番が、角の縞模様 → 橋の模様になる
3. 糸が集まったら、崖際の割れ石へ角先を差し込む
4. 横へドラッグ — 糸が角からほどけ、向こう岸へ支持線が張られる(4本)
5. 円を描いて織り目を作り、最後に逆回転で橋面が閉じる
6. 橋面に触れる — ユニコーンが前蹄で張力を確かめる
7. 向こう岸をタップ — 一歩ずつ重心を移しながら渡る
8. そのあとも自由に: 残り糸で手すりを巻く、行き来する

次に遊ぶときは雨粒の位置と色の並びが少し変わります。
「巻く → ほどく → 橋になる」の規則は変わりません。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型検査 + ビルド
npm run preview    # dist/ を配信 (ポート4173)
npm run test:e2e   # Chromium スモークE2E (要: Playwrightブラウザ)
```

環境に固定の Chromium がある場合は `PW_CHROMIUM_PATH=/path/to/chrome` を指定。

`?e2e=1` を付けると固定シード・固定タイムステップ・無音になり、
`window.__game` / `window.__tick` から決定的に検証できます。

## 実装メモ

- Vite + TypeScript + Three.js。物理シミュレーションは使わず、
  スプライン追従チューブ(糸)・事前定義螺旋(巻き取り)・カテナリ近似(支持線)・
  少数制御点のたわみ(荷重)で因果を表現
- 巻き取り: 指の円ジェスチャーの符号付き角度を蓄積。速度が巻きの整い方に、
  順番が縞模様に残る
- 橋: 支持線は消費した糸束の色が区間ごとに反映され、荷重経路
  (固定石 → 結び糸 → 支持線 → 織り目 → 橋面)が視覚的に読める
- 影はユニコーンと橋接触部周辺のみ。内部解像度はフレーム時間で自動調整
- 画面回転しても状態は保持(リロードなし・リサイズのみ)
