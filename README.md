# こうえんの こうじげんば — 公園の滑り台をつくるモバイル Web ゲーム

現実的な公園の工事現場で、小型移動式クレーンと remote pendant を操作して
大きな滑り台を組み立て、完成後に試験ボールと最初の試滑を見るゲームです。
iPhone / iPad の縦横どちらでも遊べます。

- TypeScript + Three.js (WebGL 2) + Vite
- バックエンド・ログイン・通貨・広告なし
- 素材テクスチャは canvas で手続き的に生成（外部アセットなし）

## うごかす

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型検査 + production build
npm run preview    # dist を配信（http://localhost:4173）
npm run test:e2e   # Chromium での E2E（要 Playwright ブラウザ）
```

デバッグ用のクエリパラメータ:

| パラメータ | 効果 |
| --- | --- |
| `?fast=1` | 決定論的・低負荷モード（E2E_FAST 相当）。進行が 3 倍速になる |
| `?q=low\|medium\|high` | 描画品質ティアを固定する |

## 操作

一つの gesture に一つの機械動作が対応します。カメラ操作は gesture に割り当てません。

| 操作 | 機械の動き |
| --- | --- |
| 左下ペンダントの大きな上下レバー | 巻上げ／巻下げ（吊荷が上下する） |
| 画面内の横スワイプ | 旋回（ジブが安全な範囲で横移動する） |
| 右下の回転ハンドルを円運動 | 吊荷の向きを微調整 |
| 大きなボルトの上で指を円運動 | 締め付け |
| ピンを指で押し込む | 代表ピンの挿入 |
| ボール／こどもを前へスワイプ | 試験流し／最初の滑走 |

スワイプの向きは毎フレーム画面へ投影して決めるので、カメラが変わっても
「画面の右へ動かせば吊荷は右へ動く」が保たれます。

## 安全と補助

- 吊荷は自由剛体ではなく、制約された軌道（旋回角 × 巻上げ高さ × 向き）で動きます。落下しません。
- 経路の途中には「保つべき高さ」があり、上がりきっていない間は旋回が止まり、レバーを上げるよう促します。既設部材へぶつかりません。
- 作業員は吊荷の下に入りません。介錯ロープ係は部材の短辺方向へ、合図者は取付位置の向こう側に立ちます。
- 取付位置の近くまで運べば、多少ずれていてもタグラインと作業員の誘導で最後だけ穏やかに着座します（`uTol` の 2.6 倍まで許容）。
- 一定時間操作がないと矢印とレバーの脈動でヒントを出し、それでも止まったままなら自動補助がゆっくり正解方向へ寄せます。

## 建設工程

`src/build/layout.ts` に、接続位置・許容範囲・使用 gesture・camera preset・次工程を
data として持たせています。工程は state machine (`src/game.ts`) が読みます。

一回目（`ROUND1`）:

1. 現場全景を見る
2. 一本目の支持柱を基礎へ降ろす
3. 二本目の支持柱を置く
4. 踊り場 platform を柱へ載せる
5. 代表ピンを二本差す
6. 階段を platform へ接続する
7. 長い滑走面をクレーンで吊り上げ、上端 bracket と下端 foot を位置合わせする
8. 大きな代表ボルトを三本締める
9. 左右の手すりを装着する
10. 作業員が目視点検する
11. 完成形を開始と同じ画角で見る
12. 軽い試験ボールを流す
13. 工事柵を開き、キャラクターが最初に滑る

二回目以降（`ROUND2`）は短縮版で、最後の滑走区間だけを三つから選べます。
支持構造と接続法、出口の高さは共通です。

| 区間 | 形 | 滑り方 |
| --- | --- | --- |
| まっすぐ | 入口 18°→ 最急 32°→ 出口 0° の滑らかな曲線 | なめらかに加速して走り出しで止まる |
| なみなみ | 最後の 40% にひと山（端で値も傾きも 0 に戻る） | 山の手前で一度ゆるみ、その先で再加速する |
| ローラー | 最後の 38% がローラーベッド | 転がり摩擦が小さく、いちばん速く遠くまで走る |

## 部材の状態

各部材は `PartStatus`（未搬入 / 玉掛け / 吊上げ / 移動 / 仮位置 / 接続 / 固定 / 検査済み）を持ちます。
`PLACEMENTS` が仮置き姿勢・取付姿勢・フック点・スリング取付点・許容範囲・
経路上の必要高さを一括で持ちます。

## 構造と重量感

- 支持柱は地面へ貫通させず、コンクリート基礎の base plate とアンカーボルトへ接続します。
  ベースプレートには実際に穴があり、降下中に穴とボルトが同じ画面に入ります。
- 踊り場は 50 mm デッキ + 110 mm の下部フレーム（リップ溝形鋼）。
- 滑走面は断面（床板・側壁・接続フランジ・長手リブ）を掃引した一体成形で、
  横リブと中間支持を持ち、自重でたわんで見えないようにしています。
- 手すりはデッキへフランジとボルトで留まり、階段側の手すりと突き合わさります。
- 長尺の滑走面は天秤（spreader beam）で二点吊り。スリング長が前後で違うため、
  部材は取り付け時と同じ勾配で吊り下がります。
- 吊荷にはばね・減衰でわずかな遅れと慣性があり、接地後に収束します。
- 繊維スリングと介錯ロープは緩むと垂れ、張力がかかると直線化します。

## 品質の段階調整

`src/core/env.ts` が WebGL renderer 文字列・コア数・deviceMemory から
low / medium / high を選び、内部解像度・影マップ・接地影・背景植生・
吊荷の二次運動・地面の細かい散乱物を切り替えます。
実測 FPS が 26 を下回ると 1 段階下げます。SwiftShader は必ず low になります。

`?fast=1` のときは devicePixelRatio 1・固定シード・進行 3 倍速で、
`window.__slide` からシミュレーション時間を直接進められます。

## テスト

`tests/e2e/build.spec.ts`:

1. 一回の建設を通して、試験ボールと最初の滑走まで到達する
2. 画面回転で建設状態が巻き戻らない
3. 二回目は最終区間を選べて、滑り方（速度）が変わる
4. タッチ操作でクレーンを動かし、一本目の柱を据え付けられる

Playwright は Chromium のみ・workers=1・retries=1・maxFailures=1・video 無効で走ります。
プリインストールされた Chromium を使う場合は `PW_CHROMIUM_PATH` を指定してください。

```bash
PW_CHROMIUM_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npm run test:e2e
```

なお SwiftShader 上では FPS・アニメーションの滑らかさ・最終的な見た目の品質は
判断できません。GPU・視覚回帰・性能のテストはハードウェアアクセラレーションのある
環境で行ってください。
