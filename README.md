# 雪下にんじん (Snow-Buried Carrots)

4歳児向けのモバイルWebゲーム。一面の雪をはらって、下に隠れているにんじんを見つけ、
葉をつかんで上に引き、スポンと抜いて木箱に入れる — それだけのゲームです。
文字は一切出てきません。失敗も、時間制限も、枯れることもありません。

A wordless mobile web game for four-year-olds: sweep the snow off a winter
field, find the carrot tops hiding underneath, pull until the carrot pops
free, and drop it in the crate. Then find the next one.

---

## 遊びかた / How to play

指一本だけで遊べます。文字による説明は出ません — 手のアイコンと矢印が動きを教えます。

| | 操作 | おきること |
|---|---|---|
| 1 | 光っている場所を **タップ** | 畑がその場所に寄る |
| 2 | 雪の上を **なでる** | 雪がどく → 土の茶色が見えてくる |
| 3 | そのままなでつづける | 葉先の緑が出てくる → 土をはらう |
| 4 | 葉のあたりを **上へひっぱる** | 少し抵抗して、スポンと抜ける |
| 5 | にんじんを **木箱へはこぶ** | 近づけると吸いこまれて コトッ |

精密な操作は要りません。葉が少しでも見えていれば近くを触るだけでつかめますし、
運ぶのを途中でやめても、しばらくすると自分で木箱に飛んでいきます。
4本収穫すると新しい雪がふって、また畑が真っ白になります。

## 色の順番

このゲームの芯は「白の世界から色が出てくる」ことです。順番は必ずこうなります。

```
白（雪）  →  茶（湿った土）  →  緑（葉）  →  橙（にんじん）
```

## 動かしかた / Running it

ビルド済みの `dist/bundle.js` をリポジトリに含めてあるので、
静的サーバーに置くだけで動きます。

```sh
python3 -m http.server 8080      # あるいは任意の静的サーバー
# → http://<PCのIPアドレス>:8080/  を iPhone / iPad の Safari で開く
```

ソースから作り直す場合:

```sh
npm install
npm run build      # src/ -> dist/bundle.js (esbuild, target safari15)
npm run watch      # 開発中の自動ビルド
```

外部アセットはひとつもありません。テクスチャは起動時に Canvas 2D で生成し、
効果音は Web Audio で合成しています。オフラインでもそのまま動きます。

## 技術メモ / Implementation notes

**3D** — three.js による透視投影の実3D空間です（CSS疑似3Dではありません）。
近景の雪粒・土の湿り・葉脈、中景の畝と作業スペース、遠景の冬田・農具小屋・
林・山なみが、遮蔽と視差とフォグで奥行きとして見えます。

**雪** — 畑の雪は高さ場です。雪の厚みを `RGBA` のデータテクスチャに持ち、
スワイプでその値を削ると、頂点シェーダが実際に形を凹ませ、厚みが尽きた画素は
`discard` されて下の土が現れます。フェードではなく本物の遮蔽なので、
「どけたぶんだけ出てくる」感触になります。どけた雪は縁に寄って盛り上がります。

**隠れていること** — にんじんの葉のシルエットを半径ごとに測り、それに雪の安息角の
円錐をかぶせた形を雪の下限にしています。葉がどう広がっても必ず埋まり、
かつ雪面はわざとらしい平らな台にならず、自然なふくらみになります
(`tools/q.mjs` が全ラウンドでこれを検証します)。

**カメラ** — 距離ではなく「画面の短辺に何メートル入れたいか」で構図を決めています。
そのため iPhone の縦持ちでも iPad の横持ちでも同じ絵になります。畝は奥へ向かって
走っているので、縦長の画面では列が画面の長辺に沿って並びます。

**音** — 全て Web Audio による合成音です。雪をはらうサッサッ（帯域通過ノイズ）、
土をこする低い音、抜けるときのスポン（急上昇するサイン波＋アタック＋土の余韻）、
木箱のコトッ（減衰する木の共鳴）。最初のタップで iOS のオーディオを解錠します。

**性能** — 品質段階を端末から推定し、描画解像度はフレーム時間に応じて自動調整します。
影は作業範囲だけに絞った1灯、雪の粒感はバンプマップ、降雪は頂点シェーダ駆動です。

## リポジトリの中身

```
index.html          画面の外枠（ビューポート設定・ヒント用オーバレイ・ローダー）
src/main.js         起動・品質判定・入力・フレームループ
src/game.js         ゲームの状態機械（見わたす→掘る→抜く→運ぶ→また探す）
src/field.js        畑の高さ場、雪の厚みテクスチャ、雪と土のシェーダ
src/carrot.js       にんじん本体・葉・土のかぶり・抜けた穴
src/world.js        空、冬の陽、遠景の田畑、農具小屋、林、柵、木箱、道具、降雪
src/textures.js     手続き的テクスチャ（雪・土・にんじん・葉・木・空・アイコン）
src/audio.js        Web Audio による効果音の合成
src/camerarig.js    カメラ位置の補間と、画角から距離を出す構図ヘルパー
src/hints.js        文字を使わない誘導（光る輪・手・矢印）
src/hand.js         指を追うミトンの手
src/fx.js           雪煙・土の粒・きらめき・抜けた瞬間の光
tools/              自動テスト（Chromium でひと通り遊んで検証する）
```

## テスト / Tests

Chromium（ヘッドレス）で実際に遊んで検証します。ソフトウェア描画のため
フレームレートの評価はできませんが、進行・構図・不具合は確認できます。

```sh
node tools/q.mjs        # 葉が雪から出ていないことを全ラウンドで検証
node tools/smoke.mjs iphone   # ひと通り遊ぶ（ipad / ipadls / desktop も可）
node tools/loop.mjs     # 収穫を繰り返し、ラウンドの切り替わりまで確認
```
