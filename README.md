# 月の振り子時計 — Moon Pendulum Clock

夕方から夜へ移り変わる丘の公園。ブランコの一往復が、公園の大きな
キネティック時計の一刻みになります。時計が進むと空の色が変わり、
町の灯りが順に点いていきます。

文字による説明はありません。すべて因果で伝えます。

```
ブランコが最下点を通る
  → センサーが見る
  → 連結ロッドがレバーを押す
  → ラチェットが一歯進む
  → 歯車列が上へ伝える
  → 指標リングと分針が動く
  → 空の色が少し変わる
  → 灯りが一つ点く
```

## 動かす

```bash
npm install
npm run dev        # http://localhost:5173  (--host なのでスマホ実機からも開けます)
```

本番ビルドとローカル確認:

```bash
npm run build      # 型チェック + dist/ へ静的出力
npm run preview    # http://localhost:4173
```

`dist/` は完全な静的サイトです。外部アセットもネットワーク通信もありません
（ジオメトリ、テクスチャ、音はすべて実行時に手続き生成しています）。

## 操作

指一本で、ブランコの進む向きへ弧を描くようにスワイプするだけです。

タイミング判定はありません。向きが逆でも失敗にはならず、次のポンプが
少し小さくなるだけです。振幅が小さいときほど補助が強く効きます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/core/GameState.ts` | 時刻・段階・灯りグループの唯一の状態。1周期に1回だけ `tick()` |
| `src/core/Lighting.ts` | `night` 0→1 から連続パラメータ（太陽高度、天空色、露出、星、虫の声…）を導出 |
| `src/sim/Pendulum.ts` | 振り子物理。最下点通過と頂点で位相イベントを発火 |
| `src/scene/ClockMachine.ts` | 非接触センサー、連結ロッド、ラチェット、歯車列、保護ガラス、基礎、保守扉 |
| `src/scene/Swing.ts` | 支柱、鎖、座面、乗り手（振幅に連動する上体・脚・髪・荷重） |
| `src/scene/Town.ts` | 谷の地形、instancing の建物と手続き窓シェーダ、道路・塔・港・尾根の灯り |
| `src/scene/Sky.ts` | 空ドーム、雲、星（単一 Points）、月と位相 |
| `src/scene/Lights.ts` | 照明器具レジストリ。点灯順・立ち上がりのちらつき・地面の光溜まり |
| `src/render/CameraRig.ts` | 縦横それぞれの固定3/4視点。自由カメラなし |
| `src/audio/AudioEngine.ts` | WebAudio による合成音。最下点→機構→時計→灯りの順で鳴らす |

## 設計上の約束

- 一周期に一度だけ時刻イベントを発火します（最下点通過のうち駆動方向のみ）。
  逆方向の通過はラチェットの再係合音だけで、時計は進みません。
- 画面回転で時間状態は戻りません。リサイズ処理はゲーム状態に触れません。
- 遠景の灯りは動的ライトを使いません。emissive、instancing、加算スプライトです。
- 高DPI端末では内部解像度を制限し、フレーム時間に応じて自動的に下げます。
- 広告、課金、ログイン、時計学習テスト、ランキングはありません。
