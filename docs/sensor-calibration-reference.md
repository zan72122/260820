# センサー調律リファレンス

「見えない目の調律室――入る人だけ見つけよう」が基礎とする実在方式と、
ゲーム内での可視化・判定ルールをここに定める。

## 採用した実在方式

基礎としたのは、自動引戸用の複合(デュアルテクノロジー)センサー
**BEA IXIO-DT1** 系の構成である。一つの筐体に、役割の異なる
二つの検知技術を収める方式で、業界で広く使われている。

| 項目 | 実機(IXIO-DT1系) | 出典 |
|---|---|---|
| 接近検知 | K帯マイクロ波ドップラーレーダー(動体検知・作動用) | BEA 製品資料 |
| 戸口保護 | アクティブ赤外線(AIR)プレゼンスカーテン 2列×24スポット(計48) | 同上 |
| スポット寸法 | 床上でおよそ 2×2インチ(約5×5cm) | 同上 |
| 取付高 | 6.5〜11.5 ft(約2.0〜3.5 m)。本作は無目下 約2.3 m を想定 | 同上 |
| 検知領域 | 取付高に応じて変化。アンテナの俯角・左右角の機械調整と、リモコンによる感度段階(10段階)で追い込む | 同上 |
| 一方向検知 | 扉へ近づく動きにのみ反応し、遠ざかる動き(退出者)は無視できる | BEA/業界資料 |
| 設置時の調整 | 通常運転の赤外線は不可視。設置・点検時のみ専用のスポットファインダー等でスポット位置を確認する | 同上 |

参考にした主な公開資料:

- BEA「IXIO-DT1」製品ページ・仕様書(K帯マイクロ波+高密度AIRカーテン、
  取付高 6.5–11.5 ft、2×24スポット、感度10段階)
- BEA・TORMAX 等の引戸用センサー解説(一方向検知レーダー、
  アンテナ角度の機械調整により検知領域の位置を合わせる)

## ゲーム内でのモデル化

一つの魔法センサーに混ぜず、実機どおり **役割の異なる二つの目** として扱う。

### 1. 接近検知(ActivationField)— レーダーの目

- 床面上の台形領域として表現する(扉際幅 → 最遠端幅へ広がる)。
- **角度リング**(筐体下部の機械式ノブ)がアンテナ俯角に対応し、
  領域の**奥行き**を変える。俯角が浅い=遠くまで届く=横切り廊下まで
  はみ出す、が最初の誤設定である。
- **幅スライダー**が検知幅の設定に対応する。
- 判定は「領域内にいる」だけでは成立しない。ドップラー方式に倣い、
  **センサーへ近づく速度成分**が閾値以上の対象のみが作動させる
  (一方向検知)。遠ざかる対象・静止した対象は開扉させない。
- 誤検知抑制のため短い滞在時間(dwell)を要求する。

### 2. 戸口保護(SafetyCurtain)— 赤外線カーテンの目

- 敷居に沿って床へ並ぶ **有限個の検知セル(2列×14)** として表現する。
- 対象の bounding volume(床投影円+高さ)とセルの重なりで在/不在を決める。
- 静止していても検知する(プレゼンス検知)。閉扉中に遮られると
  減速・停止(OBSTRUCTION)→反転(REVERSING)→全開→保持(HOLDING)。

### 3. 扉状態機械

CLOSED / OPENING / OPEN / HOLDING / CLOSING / OBSTRUCTION / REVERSING
を明確に区別する(`src/sim/DoorStateMachine.ts`)。

## 可視化ルール(診断モード)

実機で通常運転中の赤外線・マイクロ波は**肉眼で見えない**。本作もこれを守る。

- 通常運転時: センサーの光や領域は一切描かない。赤いレーザー描写は禁止。
- 誤作動を一度経験した後、筐体下の**点検レンズ**が機械的に開き、
  下スワイプで**診断モード**に入る。これは実機設置時の
  スポット確認治具(スポットファインダー等)に相当する
  「試験用オーバーレイ」という設定である。
- 診断モードの表現:
  - 接近検知領域 = 床上の低密度なセル(点)+外縁の弱い照度差の線
  - 検知されたセルだけを一瞬明るくする
  - 安全カーテン = 床に並ぶ小さな検知セル。遮られたセルが分かる
  - 対象の進行は車輪の向きと短い軌跡で示す
- 画面全体を覆うホログラム・ネオン表現はしない。オーバーレイの輝度は
  実世界の材質より明るくしない。
- **診断表示と判定は同じ `SensorField` データを共有する**
  (`ActivationField.cells` / `SafetyCurtain.cells` を描画と判定の両方が参照)。
  表示を消しても判定は変わらない(受け入れ試験6で自動検証)。

## 簡略化した点(正直な注記)

- 実機のAIRカーテンはセンサーから床へ向かう赤外スポット列で、
  遮蔽は光路上のどの高さでも起きる。本作は床セル×対象の
  bounding volume の重なりで近似した。
- マイクロ波のアンテナ選択(広角/狭角ボード)は「幅スライダー」に、
  俯角調整は「角度リング」に単純化した。実機の10段階感度は
  接近速度閾値として固定値にした。
- ガラス反射・床面材質による誤検知(実機の設置注意事項)は、
  誤設定の物語(領域のはみ出し)に集約し、個別にはモデル化していない。
