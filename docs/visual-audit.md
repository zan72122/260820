# 目視監査

企画で指定された 6 つの失敗モードについて、実機相当の解像度で撮影し、
1 度の監査で見つかった問題と、その修正を記録します。

撮影解像度: 390×844 / 844×390 / 1024×1366 / 1366×1024
撮影段階: 袋付き・袋外し・シート途中・最初の反射・色づき途中・色づき後・自由配置

| 監査項目 | 初回の所見 | 対応 |
| --- | --- | --- |
| モモがプラスチック球に見える | **該当した。** 真っ白でつるりとした球だった | 原因は 2 つ。① `sheen: 1.0` が果皮全体に白いコートを敷き、blush mask の色を完全に打ち消していた（`sheen 0.4` / 彩度を落とした sheenColor へ）。② `envMapIntensity 0.7` で空を映していた（0.22 へ）。あわせて果皮のベースを白から淡い麦わら〜緑白へ、縫合線を texture と normal に焼き込み、色づきを「麦わら→杏→深紅」の 2 段ランプに変更 |
| 産毛が白い発光輪郭に見える | **該当した（別方向に）。** fuzz shell の alpha texture がセル 78 個 / 256px で 1 セル 3.3px しかなく、産毛の点が mip に消えて産毛が存在しなかった | セルを 26 に、点半径を拡大。さらに shell の alpha を「正面 0.05 + 輪郭 0.95」の重みに変え、輪郭でだけ立つようにした。shell の色は下の blush を拾うので、熟した頬の上では産毛も桃色になる |
| シートが鏡または板に見える | **該当した。** roughness の下限が 0.42 で空を映し、青い樹脂パイプに見えた | roughness を 0.68–0.90 に、`envMapIntensity` を 0.16 に、sheen を 0.12 に。折り目 normal を強め、幅を数％ゆらし、縁を常時わずかに浮かせた |
| 反射光が魔法のビームに見える | 該当しなかった | 光線は一切描いていない。最初の反射では、シート表面の明度・モモ下側の補助照明・産毛 rim・接地影の持ち上がりが同時に変わり、埃が一度だけ反射方向を横切るだけ |
| 果実とシートの因果が一画面で読めない | **該当した。** 初期の広角は縦画面で被写体まで 8m 引いてしまい、地面ばかりが写っていた | カメラを「球を収める」方式から「メートル指定の frame box を縦横それぞれで収める」方式へ変更。縦持ちはシートに沿って（ロール→シート→モモ→太陽が縦に並ぶ）、横持ちは 3/4 の斜め構図に切り替える。太陽の軌道も仰角 9–23° へ下げ、同一画面に太陽が入るようにした |
| 指が色変化を隠す | 該当しなかったが余裕がなかった | ドラッグ中は注視点を 7.5cm 下げ、被写体が指の上へ逃げるようにした。シートは常に画面下部、モモは中央〜上部 |

## 併せて直したもの

- 空の equirect が上下反転しており、天頂に地面半球の色が出ていた。
- 空の下半球が地平線色から不連続で、遠景の上に褐色の帯が出ていた。
- 紙袋の落下姿勢がゲーム状態ではなく専用タイマー由来で、フレームが飛ぶと
  裸のモモの上に袋が浮いたままになった。状態から導出する形に変更。
- 影の ortho frustum が狭く、太陽が低いとき地面の影が落ちなかった。
- 背景樹が主役の真後ろに生え、1 枚板の canopy が見えていた。カメラが向く
  範囲から近景の樹を外し、canopy を小さな塊 9 個に分割した。
- 小石が空を映して青いガラス片に見えていた。

## 撮影中に見つかった機能上の不具合

- 最初の反射の演出（シートの明度上昇・埃の一往復・環境音）が、指のドラッグで
  位相が変わった場合に一度も再生されていなかった。フレーム先頭で読んだ位相と
  比較していたため、ポインタイベントで先に進んだ変化を検出できていなかった。
  ループが最後に見た位相と比較する形へ修正。
- シート端のドラッグが、実際の展開曲線（`0.28 + deploy·0.62 + reach·0.12`）
  ではなく別の係数で逆算されており、指と布の先端がずれていた。
- カメラのフィッティングが端末の safe area を無視しており、ノッチ側で果実の
  一部が欠ける可能性があった。
- iPad 縦（4:3）では高さ側でフィットが決まってカメラが寄りすぎ、開幕の画面から
  巻かれたシートが下へ抜け落ちていた。縦構図のフレーム高とカメラ高を上げて、
  「袋つきモモ・畳まれたシート・地面」が同時に読める状態へ戻した。
- 色づき観察の接写が果実の肩を切っていたため、フレームを一回り広げた。

## この環境で判定していないこと

クラウド実行環境は SwiftShader（ソフトウェアラスタライザ）で、実測フレーム
レートは数 fps です。**FPS・アニメーションの滑らかさ・最終的な見た目の品質は
ここでは判定していません。** GPU・視覚回帰・性能テストは、ハードウェア
アクセラレーションが確認できるローカルまたは CI ランナーで実施してください。
